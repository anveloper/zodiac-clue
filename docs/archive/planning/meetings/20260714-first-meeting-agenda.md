## 1. 과제·목표 공유 (5분)
- 주제: "AI를 활용한 게임 제작", 심사자가 직접 플레이 가능해야 함
- 제출물 5종 필수: ①빌드+소스(GitHub) ②플레이영상(YT 30~60s) ③게임 소개문서 ④**AI 활용 기술문서** ⑤팀원 롤 기술서
- 마감: **08-10 제출** → 08-22 발표 → 09-04~06 본행사(48h, 판교 오프라인)

## 2. NHN 분석 브리핑 → 전략 합의 (10분)
- 핵심: NHN은 **AI를 "쓰는 사람"이 아니라 "설계·디렉팅하는 사람"**을 찾음 (2026.7.1 Claude 전사 도입, 본행사 산출물=에이전트 설계문서·디렉팅 명세)
- 본업/성장축 = **웹보드 + IP 캐주얼/퍼즐** → 우리 장르 선택에 반영
- 합의할 것: "**AI가 코어인 퍼즐/보드형 캐주얼**" 방향으로 갈지 팀 컨센서스

## 3. 게임 컨셉 결정 ★ (20분) — 가장 중요
- [ ] **방향 택1 (현재 후보 A~F, 상세는 `brainstorming/20260714-game-ideas.md`)**:
  - **Ⓐ** 하루1회 생성(퍼즐/방탈출/글자맞추기)
  - **Ⓑ** NPC 랜덤 대화
  - **Ⓒ** 하이브리드(일일생성 코어 + AI 힌트/NPC)
  - **Ⓓ** AI 규칙 추리(Zendo류, AI가 심판) — load-bearing 최상
  - **Ⓔ** 포커 + 방치형 경제(부속 컨텐츠) — NHN 본업 정합
  - **Ⓕ** NHN 주력 × 방치형 하이브리드 (E의 일반화) — 매출 트렌드 정합
    - ⭐ 유력: **F + AI 자동플레이 디렉터** (매출트렌드+본업+load-bearing AI+"디렉팅" 철학 동시 충족)
- [ ] **코어 메커닉** 구체화 — "AI 없으면 성립 안 되는(load-bearing)" 요소가 뭔가?
- [ ] **실시간성 수준**: 매 프레임(→온디바이스 모델) vs 행동/턴 단위(→서버리스면 충분)
- [ ] AI의 역할 정의: 생성? 판정? 대화? 난이도 조절? NL 이해? 자동플레이 디렉팅?
