3. 개인별 상세

3.1 안성진 풀스택 개발자 · 4년차

개발 총괄 / 구현 / 문서 / 인프라

  • 저장소 전체 구현: 모노레포 → Colyseus 서버·클루 룰 → Phaser/Three 다중 뷰 → LLM NPC → 배포.
  • AI 연동 설계: apps/server/src/ai/narrator.ts(Gemini 표현 계층 + 폴백·캐시·타임아웃), 진실/표현 경계 규약.
  • 배포·인프라: Vercel(클라) + Oracle Cloud(서버) + GitHub Actions 자동배포.
  • 문서 체계 & AI 디렉팅(상세는 제출물 ④).

3.2 이종훈 스마트팩토리 엔지니어 · 4년차

기획 / 게임 룰 설계 / 리서치 / 방향 제안

  • 게임 룰 설계: 클루형 추리 규칙(용의자·장물·방·반증·고발)을 회의체에서 함께 확정.
  • 주최사 포트폴리오·매출 분석 발주.
  • 게임 엔진·스택 비교 조사 발주.
  • 게임 방향 제안.

3.3 윤다희 프로덕트 디자이너 · 1년차

기획 / 게임 룰 설계 / 아트·에셋 / 문서 톤 · 보드 디자인

  • 기획 참여: 회의체에서 컨셉·게임 방향 논의(§5 의사결정 이력).
  • 게임 룰 설계: 클루형 추리 규칙을 회의체에서 함께 확정.
  • 문서 톤 보정: 사람용 소개·설명 문서의 문안과 톤 검수.
  • 보드 디자인: 게임 보드 배치와 방 레이아웃 디자인 변경 반영.
  • 아트: 방 이미지 원본 제공.
