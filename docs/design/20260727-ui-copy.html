1.3 문장 규칙

  • 1문장 = 1행동. 안내문이 두 가지를 시키지 않는다.
  • 금지 상태에는 반드시 "그래서 뭘 하면 되는지"를 붙인다. 방 안에서만 가능해요. → 방 안에서만 추리할 수 있어요. 입구(🚪)로 들어가세요.
  • 느낌표는 판 전체에서 3종만 — 승리 · 최후 생존 · 미반증(정답 후보). 그 외는 마침표.
  • 이모지는 줄 앞 1개. 연속 배치 금지(🎉🎉, ❌ ⚠).
  • 사용자 지칭은 내 / 나. "유저"·"플레이어"는 UI에 쓰지 않는다(문서 전용).
  • 오류 문구에 에러·실패를 단독으로 쓰지 않는다 → ~하지 못했어요 + 다음 행동.

1.4 진실값 경계 (CLAUDE.md 규약의 카피 측면)

  • UI 문안은 정답·타인 손패를 암시하지 않는다. 정답 후보는 규칙엔진이 계산한 공개 결과라 허용, 정답인 듯해요 같은 추측형은 금지.
  • 나만 보는 정보에는 반드시 (나만 봄) — 반증 카드, 계략 엿보기, 증거 노트.
  • NPC 대사 본문은 LLM 출력이므로 이 문서가 확정하지 않는다. 확정 대상은 폴백 템플릿(§8.2)과 접두 기호뿐.
  • 대사 경로 표시(✨/♻/⚙)는 진실값이 아니라 운영 메타데이터다(④ §4). 게임 상태를 말하지 않으므로 (나만 봄) 대상도 아니고, 숨기지도 않는다 → 문안 §4.4.
주의 폴백 템플릿에 대한 이 문서의 확정 권한은 "길이 예산 안에서"다. 예산은 제출물 ④ §2.3이 정하고 코드 상수 LINE_BUDGET_SUGGEST(25) · LINE_MAX(40)가 강제한다 — 예산이 문안보다 상위다.
07-27 확정본이 이 예산을 어겨 07-28에 템플릿을 교체했다. 경위는 §8.2 정정 노트.

1.6 모달 포커스 관리 2026-08-27

전면 오버레이는 열 때 포커스를 안으로 넣고, 닫을 때 연 자리로 되돌린다.

  • 버튼으로 바꾸는 것만으로는 아무것도 나아지지 않는다 — 포커스가 뒤 페이지에 남아 있으면 오버레이가 덮어서 보이지도 않는 컨트롤들을 Tab으로 지나야 모달 안에 닿는다. 도감은 실제로 그 상태였다(열어도 activeElement가 트리거 버튼).
  • Tab을 안에서 순환시킨다. aria-modal="true"는 보조 기술에만 말할 뿐 시퀀셜 포커스를 막지 않는다 — 순환은 코드가 해야 한다.
    ⚠️ 리스너를 오버레이에 걸면 구멍이 난다 — 모달 안의 포커스 불가 영역을 클릭하면 activeElement가 <body>가 되고 keydown이 오버레이를 거치지 않는다 → 덮인 배경 컨트롤로 그대로 빠져나간다(검수 실측: 배경 focusable 10개). document에 걸고 «모달 밖이면 안으로 끌어온다» 분기를 둬야 한다.
  • 선택 상태를 색으로만 말하지 않는다 — 썸네일에 aria-pressed, 바뀌는 상세 패널(#cxInfo)에 aria-live="polite". 없으면 키보드 사용자는 «이름 15개를 넘길 수 있을 뿐» 내용을 못 받는다.
  • Esc로 닫힌다(도감은 원래 있었다).
  • 실측(도감) — focusable 1 → 16개 · 열면 포커스가 기본 선택(호랑이 대감)으로 · Tab이 캐러셀을 따라 이동하고 링이 어두운 면 위에서 보인다(§1.5의 accent 예외).
  • ✅ 오버레이 버스도 해소(2026-08-27). showOverlay가 띄우는 것 중 포커스 대상이 있는 것만 «모달»로 다룬다 — 목표 카드·결과 화면은 포커스를 가져가고, 주사위·로딩 인터스티셜은 가져가지 않는다(포커스 대상이 0개라 옮기면 Tab이 죽는다).
    «pointer-events: none이라» — 틀렸다. 그건 .dice-overlay뿐이고 #viewLoad는 클릭을 전부 삼키는 전면 스크림이다. 근거는 «포커스 대상 0개» 하나다.
  • 초기 포커스는 «가장 덜 파괴적인 곳»(APG Dialog). 결과 화면의 첫 버튼 [다시 하기]는 누르는 즉시 재대국을 보내므로 거기 두면 Enter 한 번이 새 판이다 → 마크업이 [data-initial-focus]로 자리를 선언하고 결과 화면은 제목에 둔다. aria-describedby="endSub endCards"로 정답 봉투 3장까지 읽히게 한다.
  • Tab 순환·복원은 도감과 같은 헬퍼를 쓴다. ⚠️ 리스너는 두 벌이라 defaultPrevented로 서로 물러난다 — 없으면 «버스가 옮긴 포커스를 도감이 다시 뺏는» 무한 리셋이 된다.
  • 되돌릴 자리는 «보이는가»로 판정한다. isConnected만으로는 부족하다 — 이 앱은 화면을 제거하지 않고 display:none으로 끄고, 증거 노트 메모 <input>은 onblur가 자기 자신을 DOM에서 떼어낸다.
  • 실측(솔로 진입 · 실제 앱) — 진입 직후 activeElement = #goalOk(카드 안) · Tab·Shift+Tab이 안에 머문다 · 카드를 닫으면 주사위 오버레이가 떠도 포커스를 안 가져간다.

  • 🔴 모달 밖 부유 컨트롤은 «포인터로도» 못 닿아야 한다 2026-08-27 (4차)

  • 주의 #turnCircle은 배경음만 해소됐다 — 여전히 버스를 안 타므로 role="dialog"도, 포커스 트랩도, Esc도 없다. 버스에 올리는 것이 남은 일이다.
  • 주의 #viewLoad는 마우스만 막고 키보드는 안 막는다 — 청크 로딩 동안 Tab으로 아래 컨트롤에 닿는다. 정답은 inert다.
  • 예외 — 결과 화면은 Esc로 닫히지 않는다. 의도된 예외다(판이 끝난 화면에서 «닫기»가 무엇을 뜻하는지 정의되지 않는다. 나가는 길은 두 버튼뿐).

  • 🔴 조회가 문지기보다 「먼저」다. 뒤집으면 예산이 마른 IP는 있는 방에도 못 들어간다(실측 429). 남의 오타가 나를 가두는 것은 자물쇠가 아니라 사고다. 있는 방으로 가는 길은 문지기를 아예 안 거친다.
  • 거절은 기억에 안 남긴다 — 남기면 막힌 채로 계속 두드리는 공격자가 창을 영원히 연장하고 정상 사용자만 갇힌다.
  • X-Forwarded-For는 TRUST_PROXY=1일 때만 읽는다 — 그냥 믿으면 헤더 한 줄로 상한을 우회한다.
  • 실측(수리 후 재측정): 있는 방 40회 → 차단 0 · 없는 코드 200회 동시 → 통과 20(=상한)·차단 180(33ms) · 경로 변형 40회 → 40건 전부 차단 · 예산 소진 뒤에도 있는 방 통과(200).
  • 🔴 초안의 「초당 9,615 → 분당 20」은 거짓이었다. 문지기가 자기만의 엄격한 경로 정규식을 써서 라우터와 다른 URL을 봤고, joinById// 같은 변형이 그 틈으로 초당 35,088회 지나갔다 — 자물쇠 효과 0. 지금은 라우터의 토크나이저를 주입받는다.
  • 🔴 요청 하나로 서버가 죽었다. decodeURIComponent가 %ZZ에 URIError를 던졌고 그것이 async 리스너 안이라 프로세스가 내려갔다 — 인증도 레이트리밋도 거치기 전이다. Colyseus 자신은 URL을 디코딩하지 않는다.
  • 🔴 X-Forwarded-For의 맨 왼쪽은 클라이언트가 써 넣은 값이다. 초안이 왼쪽을 써서 헤더 한 줄로 200회가 전부 통과했다(차단 0). → TRUST_PROXY=<홉 수>로 받아 오른쪽에서 n번째를 쓴다.
  • 🔴 프리플라이트가 예산을 먹었다 — 실효 상한이 20이 아니라 10이었다. → POST만 본다.
  • 🔴 429의 CORS가 달라 브라우저가 응답을 버렸다 — colyseus.js는 항상 withCredentials를 붙이는데 ACAO: *는 자격증명 요청에 CORS 위반이다.
  • 🔴 있는 방은 무제한이 아니다 — joinById는 호출마다 좌석 예약을 잡으므로 코드를 아는 사람이 반복하면 그 방을 영구히 봉쇄할 수 있다(6석 방에 30회 → 예약 5·만석 25). → 별도 예산 60/분.
  • 🔴 조회 실패는 fail-closed다 — 통과시키면 드라이버가 흔들리는 순간 자물쇠만 꺼지고, 공격자가 그 상태를 유도할 수 있다.
  • ⚠️ 메모리 안에만 있다 — 프로세스가 여럿이면 프로세스마다 따로 센다. 지금 배포는 단일 인스턴스라 성립하고, 늘어나는 순간 공유 저장소가 필요하다.
  • 🔴 그 각주만으로는 부족했다 — 초안은 상한도 축출도 없어 서로 다른 키 100만 개에 heap이 +301.4 MB 늘고 창이 지나도 안 줄었다. 공격자가 IP를 바꿔 가며 두드리면 그 키들은 영영 다시 안 만져진다. → 창 지난 통을 실제로 버리고 키 수에 상한(2만)을 둔다.
  • ✅ 이 축을 실서버 HTTP로 잰다 — scripts/gate-join-guard.mjs(전체 모드 joinguard). 텍스트 검사로는 안 된다: 검수가 「감싸기를 new Server 앞으로 옮겨 자물쇠를 통째로 끈」 상태를 소스 grep 게이트로 PASS시켰다. 지금 게이트는 서버를 띄워 우회로 3종·프로세스 사망·프리플라이트·CORS·정상 참가를 요청으로 확인하고, 결함 5종 주입에 전부 FAIL한다.
