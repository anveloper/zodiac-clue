1. 확정된 결함 (실코드 검수로 확인)

P0 봇이 사람보다 더 안다 — 공정성 + 문서 신뢰도 동시 리스크

  • clue-room.ts의 revealed는 룸 전역 Set. 반증 카드가 쌓이고 모든 봇이 후보 소거에 쓴다. 사람은 자기에게 보인 카드만 안다.
  • 덱 18장·비정답 15장 기준 라운드당 봇 5명이 각 1장 노출 → 3~4라운드면 봇 지식이 수렴한다. 사람의 실제 행동 턴은 3~4번뿐.
  • AI 기술문서(제출물 ④)에 "공유 공개카드(revealed)"로 명시돼 있다 → 심사자가 "AI가 치트한다"로 읽을 수 있는 유일한 지점.

조치 — revealed를 공통 단서 전용으로 축소, 봇별 seen(자기 손패 + 자기에게 보인 카드 + 공통단서)으로 분리. 수렴 보전은 공개 정보만 쓰는 추론으로: "패스한 사람은 그 3장을 안 가짐"(notHolds)은 사람도 로그로 도달 가능하므로 비대칭이 아니다. 무한 지연 방지로 제안 상한(40) 초과 시 공통 단서 1장을 결정론적으로 추가 공개.

P0 "패스"가 로그에 없다 — 사람 쪽 정보 결손

  • doSuggestion은 첫 매치에서 🛡 X 반증만 브로드캐스트하고 return → 반증 못 한 앞 순서 플레이어가 로그에 안 남는다.
  • 정통 클루에서 "누가 못 냈는가"는 카드 내용보다 중요한 공개 정보인데, 지금은 턴 스트립과 대조해 머릿속으로 역산해야 한다.
  • 부수 기능인 peek(계략)은 증거노트에 자동 기록되는데, 주 정보원인 반증은 로그 한 줄로 끝난다 — 친절함이 역전돼 있다.

조치 — suggestLog { by, suspect, weapon, room, passed[], disprovedBy } 브로드캐스트 + 제안 기록표 패널(행=제안, 열=6인, 셀 = ·패스 / 🛡반증 / 나에게 보인 카드). 전부 공개 데이터만 쓰므로 진실값 누출 0. disprove 수신 시 증거노트 자동 cleared 기록 추가.

P0 심사축 1위(AI)가 화면에 없다

LLM 기여는 broadcast("say", {id, from, text}) 한 줄뿐이다. LLM인지 캐시인지 규칙 폴백인지, 몇 ms 걸렸는지 플레이어도 심사자도 알 수 없다. 30~60초 영상에서 "AI가 일한다"를 증명할 화면이 없다는 뜻이다.

조치 — narrate() 반환을 { text, source: "llm"|"cache"|"fallback", ms, model }로 확장 → AI 디렉터 패널(우측·기본 접힘·?ai=1이면 펼침)에 LLM n · 캐시 n · 폴백 n · 평균 Xs와 최근 발화. 로그 배지 ✨llm / ♻cache / ⚙fallback.

경계 확인 — 추가 필드는 전부 "문장이 어느 경로로 왔는가" 메타데이터이며 게임 상태가 아니다. 진실값 경계 불변. 말풍선은 3개 렌더러가 이미 동일한 showBubble(id, text) 계약이라, 배지를 문자열 접두로 넣으면 4뷰 자동 대응.

P0 1.5h 8.1 이탈자의 손패가 증발해 "유령 카드"를 만든다 — 진실값이 깨진다

removePlayer()는 players·hands에서 지우지만 turnOrder에서는 지우지 않는다. 반증 루프는 turnOrder를 돌며 hands.get(id) ?? []로 접근하므로 이탈자를 조용히 건너뛴다.

→ 이탈자가 들고 있던 카드 2~4장이 영구히 반증 불가능해지고, 그 카드를 포함한 제안이 "❗ 아무도 반증하지 못함 — 정답 후보!"로 방송된다. 정답이 아닌데 정답 후보다.

연쇄 — 봇은 "아무도 반증 못 함 + 내 패에도 없음"이면 즉시 확신 고발한다 → 유령 카드 하나가 봇 여러 명을 연쇄 오답·탈락시키고, turnOrder가 1명이 되면 "최후 생존 승리"로 끝난다. 사람 1명이 판 도중 브라우저를 닫으면 2~3라운드 안에 봇들이 집단 자살하고 판이 사고사한다.

게다가 UI가 이를 유도한다 — 탈락 배너의 유일한 버튼이 [메인으로]다. 판을 가장 확실하게 망가뜨리는 버튼이 탈락자에게 제공되는 유일한 버튼이다.

조치 — removePlayer 대신 handoverToBot: isBot=true; awayBot=true; connected=false + 기존 손패로 노트 재구성. hands·turnOrder를 절대 건드리지 않는다. 대기실에서만 완전 삭제, 재접속 시 좌석 반환.
