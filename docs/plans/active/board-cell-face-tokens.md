# 보드 셀 확대 + 얼굴 토큰 (뷰1)

## 목표
셀을 키워 **프로필(얼굴) 사진이 정상 크기 토큰으로** 보이게. 40px에선 뭉개져 이모지로 되돌렸던 것을 셀 확대로 되살린다.

## 결정 (2026-08-06)
- `CELL_PX 40 → 80` (packages/shared/content/clue/view-board.ts). `PX_PER_UNIT`는 자동 80 — **소비처 0이라 무해**.
- **뷰1만** 적용: 셀 확대 + 이모지 토큰 → 얼굴 Image 토큰(대표색 디스크 링 유지). 계략 NPC 토큰 포함.
- **뷰2·3 = 보류** (유닛 기반이라 CELL_PX 무영향. 얼굴 토큰 이관은 후속 과제).
- **뷰4 = 그대로 둠** (사용자: "뷰4는 공개 안 할 거니까 그냥두고"). pixel-scene은 CELL_PX 공유라 내부 2배가 되지만 **비공개 예정이라 손대지 않는다**(자체 카메라 fit이 흡수). 얼굴 토큰도 뷰4엔 추가 안 함. 깨져도 방치 OK.
- 줌 재조정(뷰1): `MIN_ZOOM 0.3 → 0.4` (보드 1920 × 0.4 = 768 ≈ 화면 53% → «20%까지 축소» 해소). `INIT 1.0`·`MAX 1.25` 유지(셀 80 → 화면 80px, 얼굴 ≈64px = 정상). 눈으로 보고 미세조정.
