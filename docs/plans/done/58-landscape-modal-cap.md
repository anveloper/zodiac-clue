# plan: 폰 가로·짧은 화면 모달 폭 상한

status: done(2026-08-30) · created: 2026-08-30 · src: 개선 루프 38회차

## goal
플랜 57 큐 1번. `@media (max-width: 680px), (max-height: 500px)`의 `.modal { width: 100% }`에
**절대 상한이 없었다.** 이 분기는 `max-height: 500px`도 잡으므로 **폰 가로·짧은 데스크톱**까지 온다.

## 🔴 실측 — 데스크톱보다 한 자리 심하다
| 뷰포트 | 모달 | select | 필요 폭 |
|---|---|---|---|
| 932×430 (폰 가로) | 900 | **806** | 229 |
| 1440×480 (짧은 데스크톱) | 1408 | **1314** | 229 |

37회차가 데스크톱에서 고친 「폼이 필요 없는 폭까지 늘어난다」의 **한 자리 심한 판본**이 남아 있었다.

## 설계 — 상한 380px (검수 뒤 값)
① **폼 필요 폭 336** = 라벨 52 + 간격 8 + 컨트롤 **242** + 패딩 32 + 테두리 2
② **세로 폰과 같은 컨트롤 폭 보장** — 세로 390에서 264이므로 그보다 좁아지면 회귀. 380 → **286** ✓
③ **값은 `.card`·`.goal-card`와 같은 380** — 저장소가 이미 가진 축이다.
   430·480 세로에서 모달이 398·448로 카드와 어긋나던 것이 함께 맞는다.

## 🔴 검수가 잡은 것 — 내 «실측»이 두 번 인공물이었다
1. **🔴 제약 ③(「경고 1행 필요 폭 348」)은 재현되지 않는다.**
   내 하네스가 **데스크톱 미디어쿼리 «안»의 `.modal-warn { font-size: 14px }`를 밖으로 끌어내**
   적용해 348을 얻었다. 이 분기의 실제 크기는 **12px**이고 필요 폭은 **333.4** —
   **360에서도 한 줄로 선다.** 「초안 360이 스크롤을 새로 만들었다(스스로 발견)」도
   **같은 원인의 착시**였다. 올바른 하네스(`<style>` 통째)로 재면 `scrollH`가 **전후 315로 동일**하다.
   ⚠️ **37회차의 `box-sizing` 누락과 같은 계열**이다 — 규칙을 골라 뽑으면 값을 지어낸다.
   → **하네스는 `<style>` 블록을 통째로 쓴다.** 골라 뽑으면 ① 전역 규칙을 빠뜨리거나
     ② 미디어쿼리 안의 규칙을 밖으로 끌어낸다.
2. **🔴 `select`에 저작자 `font-family`가 없었다** — 폼 컨트롤은 상속하지 않아 실측 **Arial**이다.
   그래서 §1.5.1과 37·38회차가 기댄 논증(「스택 마지막이 `sans-serif`라 `serif`·`AppleGothic`에
   닿지 않는다」)이 **select에는 성립하지 않았다.**
   🔴 **이 파일이 `.cx-thumb`(:255)와 `.char`(:451)에 그 사실을 이미 두 번 적어 뒀다** —
   또 «옆에 적혀 있는 것을 안 보고» 값을 세웠다.
   → `.modal select { font-family: inherit }` 추가. 논증이 참이 되고 폼·본문 서체도 통일된다.
   폭 영향 없음(Arial 186.6 vs 스택 185.8).
3. **🟠 필요 폭 숫자가 과대였다.** 실측은 **225**(글자 186.64 + 크롬 38.36)인데 229/191/242로 적었다.
   ⚠️ **개정 전 §1.5.1이 적고 있던 225가 정확한 값이었다** — 맞는 수를 틀린 수로 덮었다.
   서체 배수 1.066도 15px 값을 옮긴 것이고 13px 실측은 **1.053**이다.
4. **🟠 「게이트 새 FAIL 0」은 이 회차의 증거가 아니다** — 게이트는 390×844·1440×900 둘만 재고
   이 변경은 **그 두 곳을 안 건드린다**(실측 불변). done-criteria에 그대로 쓰면 안 된다.
5. **🟠 바로 위 주석이 이번 결론과 모순인 채였다** — 「폰 폭에서 모달은 카드 계열과 같은 폭으로
   선다(= 화면 폭을 따라간다)」. 그때는 카드 계열이 전부 `100%`였을 뿐이고 지금은 380 상한이 있다.
   원칙은 그대로이되 **읽히는 방식이 바뀌었다**는 것을 주석에 적었다.
