# plan: 증거 노트 칸을 «조작 요소»로 만든다 — 계측 밖에 있던 진짜 타깃

status: done(2026-08-28) · created: 2026-08-28 · src: 개선 루프 25회차 (플랜 44 큐 2번)

## goal
증거 노트는 이 게임의 **추리 도구**인데, 칸의 상태를 순환시키는 대상이 `<div>`였다.
24회차가 «폰 + 컬럼 펼침» 화면을 게이트에 넣고서야 그 사실이 드러났다.

## 진단 — 같은 자리에 두 결함
### ① 클릭 대상이 `<div>`였다
`.evi-row`에 `onclick`만 있었다 →
- **키보드로 아예 못 쓴다.** 칩 12개가 전부 마우스·손가락 전용이었다.
- role이 없어 화면 게이트 S3의 «조작 요소»에 **안 잡힌다** → 44px 하한을 **한 번도 안 쟀다.**

🔴 **24회차가 «44px을 확보했다»고 적은 것은 ✎ 버튼 얘기였다.** 정작 상태를 바꾸는 타깃은
**20px**이었고, 그때는 `<div>`라 계측 대상이 아니어서 안 보였다.
버튼으로 바꾸자마자 게이트가 **`74.5×20`** FAIL을 찍었다.

### ② `opacity`로 상태를 말하고 있었다
`.evi-chip.cleared { opacity: 0.4 }` · `.own { opacity: 0.5 }`.
칩 전체가 투명해져 글자·배경이 **같이** 패널 쪽으로 내려간다 — 직접 계산:

| 상태 | 불투명 | 실렌더 |
|---|---|---|
| `.cleared`(opacity 0.4) | 9.78 | **2.12 ~ 2.14** ← AA 4.5 미달 |
| `.own`(opacity 0.5) | 9.78 | **2.67** ← 미달 |

**S6는 합성 전 색을 읽으므로 원리적으로 못 본다.**
13회차가 대기실 격자에서 고친 **똑같은 함정**(`opacity: 0.35` → 1.87)이 증거 노트에는
그대로 남아 있었다. 그리고 «제외»는 판에서 **가장 흔한 상태**라 —
카드를 지워 나가는 것이 이 게임의 진행이다 — **패널 대부분이 안 읽히는 상태였다.**

## 처방
```ts
const hit = document.createElement("button");   // 아이콘 + 이름 · onclick · title
hit.className = "evi-hit";
row.appendChild(hit);                            // 메모 버튼과 **형제**(버튼 중첩은 무효 HTML)
```
```css
.evi-hit { flex: 1; align-self: stretch; /* 전역 button 규칙 무력화 */ }
.evi-chip.cleared {
  color: var(--wds-label-alternative);            /* 칩 배경 대비 5.72 */
  text-decoration: line-through;
  text-decoration-thickness: 2px;                 /* 11회차: 12px 한글에서 1px은 안 보인다 */
  text-decoration-color: var(--wds-primary-normal); /* 4.04 · 1.4.11 하한 3.0 */
}
.evi-chip.own { border-style: dashed; }           /* opacity 제거 — 파선이 «못 누른다»를 말한다 */
```
- **`align-self: stretch`가 핵심이다** — 행 높이(coarse에서 ✎ 버튼 때문에 44px)를 **그대로 쓴다.**
  높이를 새로 더하지 않으므로 레이아웃 비용이 **0**이다.
- 잠금 칩은 `disabled`가 아니라 **`aria-disabled`**(13회차 선례) — 포커스에 남아야
  «왜 안 바뀌는지»를 읽는다.
- 상태 낱말(`미정`/`제외`/`의심`)은 칩 폭이 좁아 화면에 못 넣는다 → `aria-label`로 준다.

## 🔴 검수가 뒤집은 것 ① — `button:hover`가 새서 **상자 전체가 진갈색**이 됐다
`button:hover`(0,1,1)가 `.evi-hit`(0,1,0)를 **특이도로 이긴다.** 실측 대비:
미정 **1.47** · 제외 **1.16** · 의심 **1.98:1** — 글자가 사라진다.
**이 파일이 바로 위에 그 함정을 적어 뒀다** — `.cx-thumb`는 `.cx-thumb:hover`를 **선언해서**
(0,2,0)으로 이긴다. 나는 「15회차와 같은 처리」라고 적고 **그 한 줄을 빠뜨렸다.**
게이트는 «평상 상태만» 재므로 영원히 못 잡는 축이다.
→ `.evi-hit:hover`. `.evi-memo-btn`도 **원래부터 새고 있었다** — 같이 막았다.
같은 이유로 `.cx-thumb` 주석의 4축 중 **`appearance`·`-webkit-tap-highlight-color`도 빠뜨렸다**
(`appearance`는 「사파리/iOS 렌더를 지배하는 축 · 헤드리스 크롬으로는 안 보인다」고 그 주석이
못 박아 둔 항목이다). `border-radius`도 평상 8 → 포커스 6으로 튀던 것을 명시로 고정했다.

## 🔴 검수가 뒤집은 것 ② — 취소선이 **내 메모와 ✎를 관통했다**
`text-decoration`은 **자손이 끌 수 없다**(전파가 페인팅 단계다) — `.evi-memo`의
`text-decoration: none`은 **죽은 선언**이었다. `opacity: 0.4` 시절엔 흐려서 안 보였고,
색·두께를 올린 이번 변경이 그걸 전면에 끌어냈다 — **«덜 구분된다»가 아니라 «엉뚱한 것까지
구분해 버리는» 회귀**였다. → `.evi-chip.cleared .evi-name`으로 **이름에만** 건다.

## 🔴 검수가 뒤집은 것 ③ — 「의심」은 **여전히 색 단독**이었다
`.suspect` 배경 ↔ 칩 배경 = **1.15:1**(면 대비). 적색맹에겐 같은 면이다.
「색만으로 말하지 않는다」를 근거로 삼아 놓고 **상태 3개 중 2개만 고친** 셈이었다.
→ 「제외」와 **대칭**인 모양 단서(같은 2px 강조색 선, 위치만 아래 = 밑줄). 폭 비용 **0**.

## 🔴 검수가 뒤집은 것 ④ — 수치·문안
- `primary-normal` 대비를 **4.04**로 적었는데 **4.71**이다(`tint-primary` 위 값을 잘못 옮겼다).
  결론(1.4.11 통과)은 유지되지만 근거는 못 쓴다.
- 툴팁 `클릭: 없음(제외) → 의심 → 초기화`는 ① **「클릭」이 마우스 전용 말**이고
  ② `title`은 **폰에 절대 안 뜬다**(hover가 없다) — 그런데 `opacity`를 걷어내며 시각 단서를
  줄인 대상이 바로 그 폰 사용자다 ③ 상태 이름이 `aria-label`과 **달라** 순환을 못 읽는다.
  → `눌러서 바꾸기 — 미정 → 제외 → 의심 → 미정`.
- 잠금 칩이 **같은 문장을 두 번 읽었다**(이름 + `title` 설명 중복) → 이름은 `— 자동 제외`로.
- `aria-disabled`는 **동작을 안 막는다** — Enter·클릭에서 click이 실제로 발화한다(검수 실측).
  오늘은 듣는 쪽이 없어 무해하지만 «듣는 사람이 없다»에 기대지 않고 `preventDefault`로 막았다.

## 🟡 받아들이되 이번 회차에 안 고친 것
**탭 스톱이 21 → 42로 늘었다**(칩 21개 × 버튼 2 — 내가 «24»로 어림한 것도 틀렸다).
증거 노트를 지나 제안 기록표·기록/알림에 가려면 Tab을 42번 친다. 데스크톱은 컬럼이 늘

APG **roving tabindex**(그룹당 스톱 1개 · 방향키 이동 = 42 → 3)라 별도 단위다 → 큐 1번.
