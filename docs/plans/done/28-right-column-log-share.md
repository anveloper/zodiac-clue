# plan: 우측 컬럼 배분 — 📜 기록/알림에 «보장 몫»을 준다 (S8 red 해소)

status: done(2026-08-26) · created: 2026-08-26 · src: 개선 루프 8회차 · **새 축 1순위**(상용화 가능한 뷰)

## goal
`right-column` S8은 **유일하게 남은 화면 게이트 red**였고, 상용 뷰에서 가장 눈에 띄는 미완성이었다.
📜 기록/알림은 **반증·계략·소환이 사람에게 닿는 유일한 통로**인데 컬럼의 14.2%만 받고 있었다.

## 결함 (실측 · 1440×900)
```
컬럼 868px    #aiPanel 122px(14.1%) · #eviPanel 260px(30.0%) · #sugPanel 273px(31.5%) · #logPanel 123px(14.2%)
```
- 받은 몫 본문 **68px / 1줄**(줄 최소 높이 35px)
- **보장 몫 17px / 0줄** — `min-height: 72px` − 머리글·패딩 55px.
  `#logPanel`은 `flex: 1 1 0`(남는 것을 받는 쪽)이라 **지금 1줄이 보이는 것은 위 패널이 안 자란 덕이지 약속이 아니다.**
- 기준선(113px·3줄) 대비 **회귀**였다 — 래칫 3종 전부 위반.

**AI 대사 패널이 122px를 «평균 —· 모델 —»(계측 전 기본값)로 채우고 있었다** — 게임 정보 0.
컬럼에서 유일하게 게임 상태를 말하지 않는 패널이 통로의 폭을 먹고 있었다.

## 설계
| 변경 | 값 | 근거 |
|---|---|---|
| `#aiPanel` `<details open>` → `<details>` | 122px → **39px** | ④ §4 관측 요구의 표면은 **칩**이고 칩은 `<summary>` 안이라 **접혀도 보인다**. 접히는 것은 평균·모델·사유별 건수(진단 상세)와 범례뿐 |
| `.rp-log { min-height }` | 72 → **195px** | 35px × **4줄** + 머리글·패딩 55px |
| `.rp-ai { max-height }` | 신설 **40vh** | S8이 «폴백 사유가 늘수록 자란다»를 결함 근거로 지목 — 성장 상한 |
| `.rp-ai` 축소 제외 + `min-height` | `:has(> details:not([open])) { flex: 0 0 auto }` · **65px** | 검수 1번 — 접힌 패널이 자기 summary보다 작아져 **칩이 잘렸다** |
| `#aiWarn` 신설 (`<summary>` 안) | — | 검수 2번 — 전건 폴백 경고가 접힌 `#aiDetail` 안이라 **사용자에게 도달하지 못했다** |
| `.rp-log` 높이별 단계 | 820px↓ **160px**(3줄) · 700px↓ **125px**(2줄) | 검수 6번 — 짧은 뷰포트에서 4줄 보장이 증거 노트·기록표를 짓눌렀다 |

**4줄인 이유**: 제안과 반증은 **한 쌍**으로 온다. 2줄이면 «무슨 일이 있었는지»가 한 화면에 안 남는다.
게이트의 `minVisibleLines`(기능 하한 **1줄**)는 그것과 별개인 최저선이라 **올리지 않았다** —
하한을 올리면 «하한»이 아니라 목표가 된다.

**화면 게이트 `right-column` PASS.** 전체 `PASS 68 · FAIL 1` — 남은 1건은 `roomlist-ended` **플레이크**뿐이다.
게임 패널(증거 노트 260px · 제안 기록표 273px)은 **한 픽셀도 잃지 않았다.**

## 래칫 조이기 (완화 아님)
`--update-baseline --reason="…"`로 기준선을 **113px·3줄 / 보장 18.8px·0줄 → 140px·4줄 / 보장 140px·4줄**로 조였다.
조이지 않으면 되돌림이 통과한다. 이전 기준선은 «받은 몫»만 컸고 **보장이 0줄**이라,
위 패널이 자라는 순간 통로 대역폭이 0이 되는 값이었다.

## 🔴 검수가 뒤집은 판단 — 초안은 결함을 **하나 고치고 둘 만들었다**
1. **접으면 칩이 사라진다 — (A)가 틀렸다.** 「칩은 `<summary>` 안이라 접혀도 보인다」는 반만 맞다.
   `.rp-panel`은 `min-height:0`(축소 허용) + `overflow:hidden`이고 `.rp-ai`엔 `min-height`가 **없었다**.
   접으면 flex base가 ~150 → 39px로 떨어지고 **shrink는 base에 비례**하므로 접힌 패널이 자기 summary보다
   작아진다. 게다가 260px 컬럼에서 칩은 **설계상 두 번째 줄로 내려가** summary가 ~65px다.
   검수 실측(칩 가시율): 1440×900 **100%**(여유 0.1px) · 1280×720 **60%** · 1024×560 **0%** · 900×520 **0%**.
   → **1280×720은 흔한 노트북**이다. ④ §4 요구사항 3의 관측 표면이 조용히 사라졌다.
   → `:has(> details:not([open])) { flex: 0 0 auto }` + `min-height: 65px`.
2. **전건 폴백 경고가 사용자에게 도달하지 않았다 — 진짜 회귀.** `AI 대사 일시 폴백`(④ §4 요구사항 5)은
   `renderAi()`가 **`#aiDetail`**에 쓰는데 그건 닫힌 `<details>` 안이다. 남는 신호는 칩 테두리 색 하나뿐이고
   그 칩마저 1번대로 잘린다. §4.1이 정한 「테두리 색**과** 문장 한 줄」의 **반쪽만** 남는다.
   → `<summary>` 안에 **`#aiWarn`** 신설, `renderAi()`가 거기로 쓴다.
3. **결함을 고친 것이 은폐 방지 장치를 껐다.** `gate-screen.mjs`의 S8은 `always: short`
   (`short = floor < minVisibleLines`)였다. 보장이 0줄 → 4줄이 되자 `short === false` →
   기본 출력에서 **S8 블록 전체가 접혔다** — 방금 고쳐 쓴 `knownUnmeasured`(«조용히 빼면 은폐») 줄까지 함께.
   바로 위 주석이 「접히는 순간 게이트가 거짓말을 시작한다」고 적어 둔 그 일이 벌어졌다. → `always: true` 고정.
4. **낡은 거짓을 새 거짓으로 바꿨다.** 초안이 써 넣은 「이 컬럼 안의 글자 크기·대비 회귀는 아무도 안 잰다」는
   **틀렸다** — S6는 `game` 화면에서 돌고 보이는 텍스트 122개 중 **85개가 `#rightPanel` 안**이다(검수 실측).
   진짜로 사각지대인 것은 훨씬 좁다: **제안 기록표(`.sg-*`)** — `game` 화면 시점엔 제안이 0건이라 표가
   **존재하지 않고**, 표가 뜨는 판 중반에는 S8만 돈다.
   **이 플랜이 스스로 규탄한 실패 유형을 그대로 반복했다.**
5. **(E)가 절반 틀렸다 — 배경을 잘못 잡았다.** `.sg-n`은 `#FFF8EF` 위가 아니라 `.sg-row`
   (`--wds-tint-primary` `#F3E1D6`) 위다 → **4.96:1**(통과, 여유 0.46).
   그리고 `.sg-mine`은 배경을 `rgba(180,98,43,0.14)`로 **교체**한다 → 캔버스 합성 기준
   **4.10~4.49:1로 AA 미달**(직접 재계산 확인: 검정 4.10 · `#1f2b3a` 4.24 · 보드 초록 4.49 · 밝은 판 4.96).
   「최악 5.23:1 · AA 통과」는 **재현되지 않는다.** → `knownUnmeasured`에 실측 그대로 적었다.
6. **(C) «한 픽셀도 안 잃었다»는 900px 한정이었다.** 검수 실측 — 1280×720에서 증거 노트 −11% ·
   제안 기록표 −11%, 1280×501에서 −30%(증거 노트 본문이 21개 칩에 62px). 게이트가 900px 하나만 재서 안 보였다.
   → `.rp-log`의 보장을 **높이 단계별로** 낮췄다(820↓ 3줄 · 700↓ 2줄). **보장은 그 뷰포트에서 실제로
   지킬 수 있는 약속이어야 한다.**
7. 옛 주석 2건이 새 규칙과 정면 모순(«max-height 캡을 두지 않는다» · «상세를 기본 펼침으로 둔 것은») ·
   `gate-screen.mjs`의 「32% 상한」 두 번째 사본 · `--self-test`가 매 실행 찍는 「보장이 이미 0줄이라」 —
   전부 갱신.
