## 설계 — 분기가 «스스로 적어 둔 의도»를 규칙으로 옮긴다
| 규칙 | 의도(분기 주석의 말) |
|---|---|
| `.hud-ctrl { display } = grid` | 「액션 바는 **하단 데크**」 — 상단 좌측이면 6개 버튼이 폭을 먹어 배너와 겹친다 |
| `.rp-col { overflowY } = auto` | 「**컬럼 안에서** 스크롤한다」 — 문서를 스크롤시키면 보드가 통째로 밀린다 |
| `#rpToggle { display } = flex` | 폰에서 컬럼을 여닫는 **유일한 길** |

조건은 셋 다 CSS 분기 문자열 그대로(`"(max-width: 760px), (max-height: 500px)"`).

## 🔴 `top: auto`로는 못 잰다
「하단으로 내려갔는가」를 `top: auto`로 재려 했는데 **위치 지정 요소의 `top`은 사용값(px)으로
해석된다** — 실측 784px/560px/390px. `display`가 분기를 가르는 단일 신호다
(데스크톱 `flex` · 폰 `grid`).
