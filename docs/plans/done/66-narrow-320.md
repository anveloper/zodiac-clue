## 처방 — 폭이 없으면 **조판을 바꾼다**
1. **모달 라벨을 위로**(`max-width: 349`) — 라벨 열이 **52 + 간격 8 = 60px**을 먹는다.
   유도: 필요폭 **224**(§1.5.1) + 60 + 패딩 32 + 테두리 2 = 318, + 오버레이 여백 32 = **350**부터
   한 줄로 선다. **문안은 안 줄인다** — §1.5.1의 접미는 손대면 안 되는 축이다.
2. **하단 데크 3칸 두 줄**(`max-width: 359`) — 6칸 격자의 `1fr`은 `minmax(auto, 1fr)`이라
   **라벨이 긴 칸이 제 몫을 넘게 가져가고** 짧은 칸이 짜부라진다(`지름길로 가기`가 `nowrap`).
   실측 경계 **340 FAIL(25.7px) · 360 PASS**. D-패드도 한 줄만큼 올린다.
3. **대기실 조이기**(같은 분기) — 칸 폭이 ≈57px이라 이름이 두 줄로 접히는 것은 피할 수 없으니
   **접힌 채로 행간을 줄인다**(11px · S5 하한 10px 위).

## 🔴 검수가 뒤집은 판단
1. **🔴 경계 둘 다 «절벽 가장자리»였다** — 349는 여유 **0.0px** · 359는 **1.7px**(실측).
   349는 게이트의 `clipTolPx: 1` **아래**라 인라인 라벨로도 통과했다.
   43·44회차가 두 번 지적받은 실수를 **세 번째**로 반복했다.
2. **🔴 새 축을 «둘» 팠다** — §1.7이 「분기 경계는 하나여야 한다 · 새 축을 만들지 않는다」고
   못 박은 문서다. 게다가 이미 «좁은 폰» 축(365)이 있었다.
   → **`380` 하나**(`.card`·`.goal-card`·`.modal`이 쓰는 상수 · 여유 모달 +31 · `[?]` ≈52).
3. **🔴 처방이 과했다.** 진단(`1fr` = `minmax(auto,1fr)`이라 긴 라벨이 짧은 칸을 깎는다)은
   맞았는데 3칸 두 줄로 눕혀 데크가 54 → **101px**, 320에서 HUD가 캔버스의 **40%**를 먹었다.
   → 진단 그대로 처방: `minmax(0, 1fr)` + `white-space: normal` + 11px.
   **데크 높이 54px 그대로**라 D-패드를 움직일 필요가 없어진다.
4. **🔴 그 과한 처방이 겹침을 «만들었다»** — D-패드를 39px 올리다 `#rpToggle`과 **119px² 겹침**.
   저장소는 이 사고의 처방을 이미 적어 뒀는데 그것이 `max-height: 500` 안에 있어
   **폭 축으로 패드를 올릴 때는 안 걸렸다.** → 쌍 `["#rpToggle", "#dpad"]`를 계약으로.
   되주입해 **545px² 겹침을 잡는 것을 확인**했다.
5. **🔴 (E) 데크 높이 99는 틀렸다 — 실측 101**(`.hud { border: 1px }` 2px 누락).
   여유가 8이 아니라 6px이었다. 같은 파일이 다른 곳에서는 테두리를 꼬박꼬박 센다.
   → 3번 처방으로 그 상수 자체가 없어졌다.
6. **🔴 (F) 「이름이 두 줄로 접히는 것은 피할 수 없다」는 거짓**이었다 —
   320에서 **12px으로도 한 줄**이다(최장 53.3 = 칸 내부 폭 53.3). 11px이 하는 일은 **행 높이 축소**다.
7. **🔴 선언 셋 중 둘이 0px 기여**였다(검수 절제 실측) — `.char-grid { gap: 3px }`는
   `max-height: 659` tier가 **이미 같은 값**을 준다(중복). → 기여하는 하나만 남겼다.
8. **🔴 뷰포트 높이 568은 «기기 포인트 크기»** — 44회차가 「무효」라 선언한 그것이다.
   실기(−114)는 **320×454**이고 거기서는 `[잔치 시작]` 93px · `#hostHint` 111px 밖이다.
   **여백으로 될 크기가 아니다**(12칸 격자를 가진 카드가 454에 안 들어간다) → 큐로.
9. **🟠 「카드가 22px 넘친다」가 재현되지 않는다** — 실측은 `#hostHint` **20px** 밖 ·
   `#startBtn` 2px 잘림이다. 「한 형상의 값을 다른 형상에 쓴다」의 또 다른 판본이다.
