## 🔴 착수하자마자 나온 것 — **41회차가 블록 사본을 안 지웠다**
`git show HEAD:apps/client/index.html`에 `@media (max-height: 500px)` 블록이 **두 벌**이다:
`min-width: 761`(옛것) → `min-width: 681`(41회차가 «옮긴» 것). 겹치는 선언은 뒤엣것이 이겼지만
**한쪽에만 있던 선언은 그대로 살아 프로덕션에 나갔다** —
`.subtitle { display: none }` · `.char-grid { repeat(6,1fr) }` · `.char-state { min-height }` ·
`.card h1 { font-size: 18px }`.

그중 부제 감추기가 **랜딩에 회귀**를 냈다: `.game-meta`는 `margin-top: -14px`으로 **부제 밑에
붙는 줄**이라, 부제가 사라지자 **제목을 파고들었다**(캡처로 확인 — 글자가 겹쳐 보인다).
게이트는 글자 겹침을 안 재므로 못 잡았다.
**교훈: 「옮겼다」고 적을 때 «지웠는지» 확인하라.**

## 설계 — 세로가 없으면 **가로를 쓴다**(2단)
390 높이에서는 한 줄 조판이 **원리적으로 안 된다** — 손가락 하한 44px이 걸려 카드가 더 자라고,
대기실은 왼쪽 덩어리만 ≈225px · 캐릭터 격자만 ≈277px이다.
41회차의 «6열 눕히기 + 여백 조이기 + 부제 감추기»는 450만 겨우 맞춘 미봉이었다 → **전부 폐기.**

- **랜딩**: `[방 만들기]`까지 왼쪽, `— 또는 초대 코드로 —`부터 오른쪽(flex 2단).
- **대기실**: A(머리)·B(캐릭터)·C(시작) 세 덩어리. **grid로 B를 오른쪽 열에 2행 걸친다.**
  ⚠️ «C를 B 앞으로» 옮기면 2단이 쉽지만 **키보드가 캐릭터를 고르기 전에 시작에 닿는다** —
  DOM 순서를 그대로 두고 **보이는 자리만** 바꾼다.
- **게임**: `#rpToggle`(기본 `top: 50%`)이 D-패드(`bottom: 74px` · 높이 148) 범위 안이라
  가로에서 5/5점 가려졌다 → **패드 바로 위**(bottom 230). 폰 세로는 패드가 훨씬 아래라 안 겹쳤다 —
  **가로에서만 나던 결함**이다.
