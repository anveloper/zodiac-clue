# plan: 참가 시도에 대가를 붙인다 — 54회차가 깎은 자물쇠를 갚는다

status: done(2026-09-01) · created: 2026-09-01 · src: 개선 루프 55회차 (플랜 74 큐 1번)

## goal
54회차가 방 코드를 «부를 수 있게» 만들며 엔트로피를 **2⁵⁴ → 2⁴⁰**으로 깎았다.
그때 문서·주석에 「남은 격차는 **레이트리밋으로 갚아야 한다**」고 적고 큐 1번에 올렸다.
갚는 회차다.

**지금은 추측에 아무 대가가 없다** — 검수 실측: localhost 병렬 20연결로 없는 코드에
`joinById`를 던져 **초당 9,615회**. `grep -rn "rateLimit|throttle|onAuth" apps/server/src` → **0건**.
비공개 방은 이 코드가 **유일한 자물쇠**다.

## 설계 — 재는 것은 «시도»이고, 거는 것은 «대가»다
- **`joinById`의 `POST`만** 건다. 방 만들기·공개방 목록·프리플라이트는 대상이 아니다.
- ~~**성공/실패를 가르지 않는다.**~~ → **가른다.** 초안의 이 설계는 **실증에서 두 번 뒤집혔다**
  (아래 «세는 대상» 참조). 응답을 뜯는 대신 `matchMaker.query`로 **직접 묻는다.**
- Colyseus는 **자기가 `request` 리스너를 걷어내고 다시 건다**(`Server.js:168-180`).
  같은 방식으로 **한 겹 더 감싼다** — 매치메이크 경로면 먼저 보고, 아니면 원래 리스너에 넘긴다.
- IP는 기본 `req.socket.remoteAddress`. `X-Forwarded-For`는 **믿으면 위조된다** —
  `TRUST_PROXY=1`일 때만 읽는다(배포가 프록시 뒤일 때 오너가 켠다).
- 거절은 **429 + 기존 실패 문안 경로**로 나간다(클라 `showJoinFailed`).

## 🔴 «세는 대상»을 세 번 좁혔다 — 두 번은 내 실증, 한 번은 검수
1. **시도** → 한 Wi-Fi에 모여 하는 파티 게임이라 IP를 공유한다. 정상 참가가 예산을 먹었다.
2. **실패** → 방은 6석이고 시작되면 `locked`다. 7번째 사람·늦게 온 사람의 실패가 **전부 정상**인데
   예산을 먹고, 다 쓰면 **정상 참가까지 429로 갇혔다**(실측).
3. **«없는 방을 부른 횟수»** → 지금. 만석·시작됨은 방이 **있으므로** 안 센다.
   그리고 **조회가 문지기보다 먼저**여야 한다 — 뒤집으면 예산이 마른 IP가 있는 방에도 못 들어간다.

## 🔴 검수가 뒤집은 판단 — **이 회차는 자물쇠를 만들면서 자물쇠를 열어 뒀다**
검수가 서버를 띄워 직접 때렸다. 「이 상태로 커밋하면 안 된다」가 결론이었고 옳았다.

1. **🔴🔴 요청 하나로 서버가 죽었다.** `joinByIdTarget`의 `decodeURIComponent`가 `%ZZ`에
   `URIError`를 던졌고, 그것이 **`async` 리스너** 안이라 unhandled rejection으로 프로세스가
   내려갔다. 인증도 레이트리밋도 거치기 전이고, **진행 중인 모든 판이 사라진다.**
   변경 전 서버는 같은 요청에 정상 응답했다 — **내가 넣은 회귀**다.
   Colyseus 자신은 URL을 디코딩하지 않는다. → 디코딩 제거 + 핸들러 전체를 감쌌다.
2. **🔴🔴 슬래시 하나로 자물쇠가 통째로 우회됐다.** 문지기는 자기만의 엄격한 경로 정규식을
   썼는데 라우터는 **토큰**으로 본다(`url.match(allowedRoomNameChars)`). 두 파서가 다른 URL을
   보는 순간 틈이 생긴다 — `joinById//`·`matchmake//joinById`가 **초당 35,088회** 통과했다.
   문서에 적은 「초당 9,615 → 분당 20」이 **거짓**이었다.
   → 토크나이저를 **라우터에서 주입받는다**(갈라질 수가 없다).
3. **🔴 `X-Forwarded-For`의 맨 왼쪽을 썼다.** 표준 프록시는 **오른쪽에 덧붙이므로** 왼쪽은
   클라이언트가 써 넣은 값이다. 헤더 한 줄로 200회가 전부 통과했다(차단 0).
   **바로 위 주석이 그 우회를 경고해 놓고 그 우회를 켜는 코드를 썼다.**
   → `TRUST_PROXY=<홉 수>`로 받아 오른쪽에서 n번째.
4. **🔴 기억이 무한히 자랐다.** `sweep`은 그 키를 **다시 만졌을 때만** 도는데, IP를 바꿔 가며
   두드리면 영영 안 만져진다. 키 100만 개 → heap **+301.4 MB**, 창이 지나도 안 줄었다.
   「메모리 전용이다」라는 각주는 **누수를 설명하지 않는다.** → 축출 + 키 상한 2만.
   `size()`도 빈 통을 걸러 **실제 크기를 숨기고** 있었다.
5. **🔴 «있는 방은 무제한»이 방 봉쇄 경로를 열었다.** `joinById`는 호출마다 **좌석 예약**을
   잡으므로, 코드를 아는 사람이 예약 만료(15초)마다 6번씩 던지면 그 방은 **영구히 못 들어온다**
   (6석 방에 30회 → 예약 5·만석 25, 목록에서도 사라짐). → 별도 느슨한 예산 60/분.
6. **🔴 프리플라이트가 예산을 먹었다.** 브라우저는 참가마다 `OPTIONS`를 먼저 보내는데
   그것까지 세어 실효 상한이 20이 아니라 **10**이었고, 걸리는 지점이 프리플라이트라
   사용자에게는 원인 불명 실패가 됐다. → `POST`만 본다.
7. **🔴 429가 브라우저에 도달하지 못했다.** `colyseus.js`는 항상 `withCredentials`를 붙이는데
   `ACAO: *`는 자격증명 요청에 CORS 위반이라 **브라우저가 응답을 통째로 버린다.**
   Node E2E에서 잘 보인 건 Node fetch에 CORS가 없어서였다. → 오리진 반향 + `Allow-Credentials`.
8. **🔴 그 문안은 애초에 화면에 안 떴다.** 「랜딩이 서버 message를 그대로 보여 준다」고 적었는데
   `showJoinFailed`는 오류를 **콘솔로만** 보내고 고정 문장을 띄웠다 — 막힌 사람이
   「없는 방이거나 이미 시작한 판이에요」를 보는데 그 순간 그 문장은 **거짓**이다.
   → 429일 때만 서버 문장을 띄운다.
9. **🔴 게이트가 소스 grep이라 자물쇠를 꺼도 PASS였다.** 검수가 «감싸기를 `new Server` 앞으로
   옮긴» 상태(차단 0)를 통과시켰다. `/429/` 검사도 주석의 글자에 걸려 항상 참이었다.
   → **실서버 HTTP 게이트**(`gate-join-guard.mjs` · 전체 모드)를 만들었다.
   결함 5종 주입에 전부 FAIL한다(감싸기 위치·옛 정규식·CORS `*`·디코딩+무보호 async·프리플라이트).
10. **🟠 fail-open이었다.** 드라이버 조회가 실패하면 통과시켰다 — Redis로 가는 순간
    그것이 **자물쇠를 끄는 스위치**가 된다. → fail-closed(조회가 죽으면 참가 자체가 어차피 안 된다).

### 검수가 확인해 준 것
`new Server` 뒤 감싸기는 옳다(`attach()`가 생성자에서 `attachMatchMakingRoutes`를 부른다) ·
`listen()` 전후는 무관 · 헬스·404 정상 · `upgrade`는 좌석 예약 토큰이 필요해 추측 표면이 아니다 ·
「거절을 기록하지 않는다」는 옳다(창 무한 연장 방지) · LocalDriver 조회 비용은 이 규모에서 무시 가능.
