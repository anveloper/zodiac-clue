# plan: 폼은 카드가 아니다 — 모달 컨트롤 폭 상한

status: done(2026-08-30) · created: 2026-08-30 · src: 개선 루프 37회차

## goal
36회차가 `.modal`을 520으로 넓히자 `flex: 1` select가 **448px**이 됐다.
가장 긴 옵션은 그만큼이 필요하지 않아 **빈 여백이 3행 반복**됐다 —
35회차가 「폭 456px 막대에 13px 글자」라 부른 결함이 폼으로 옮겨 온 것이다.
큐가 「**값을 짓지 말고 가장 긴 옵션을 실측**하라」고 못 박았으므로 그대로 한다.

## 실측 절차
1. `cards.ts`의 `ZODIAC 12 · WEAPONS 6 · ROOMS 9`에서 `LABELS`·`EMOJI`를 뽑아
   `selectFrom`이 만드는 옵션 문자열 **81개**를 재현
   (`${cardIcon} ${label}` + 접미 `""` / `" — 정답 아님"` / `" — 내 패 (정답 아님)"`).
   ⚠️ 1차 시도는 `LABELS`를 파일 전체에서 뽑다가 **뒤의 `PERSONA`에 덮여** 설명문을
   라벨로 쟀다(최장 612px). 범위를 객체 안으로 좁혀 다시 쟀다.
2. 15px 렌더 폭 최장 = **213px** — 「🐯 호랑이 대감 — 내 패 (정답 아님)」.
3. 실제 CSS로 `select { width: max-content }` → **컨트롤 필요 폭 258px**(크롬 45 = 패딩 20 + 화살표 + 테두리).
4. 서체 배수를 **폴백별로 실측**: 현재 스택 211(=1.00) · AppleGothic 248(**1.173**) · serif 폴백 256(**1.212**).

## 🔴 유도식을 한 번 틀렸다
초안은 `258 × 1.15 = 297 → 300`으로 잡았다. **크롬(45px)에도 배수를 곱한 잘못**이다 —
패딩·화살표·테두리는 서체를 안 따른다. 바른 식은 `글자 × 배수 + 크롬`:
`213 × 1.212 + 45 = **303**` → 상한 **310**. 초안 300은 최악 서체에서 **3px 모자랐다.**

## 설계 (검수 뒤 — 아래 «검수가 뒤집은 판단» 참조)
**모달 폭을 폼이 정한다**: `.modal { width: 448px }`
→ `448 − 테두리 2 − 패딩 64 = 콘텐츠 382` → `382 − 라벨 64 − 간격 8 = 컨트롤 **310**`.
경고·안내·버튼도 전부 382 한 줄이라 **오른쪽 모서리가 하나**다.
310은 도달 가능한 최악 서체(NanumGothic 필요 폭 270)에서도 안전하다.

## 🔴 검수가 뒤집은 판단
1. **🔴 출발 수치가 틀렸다 — 「select 448px」은 없었다.** 전역 `* { box-sizing: border-box }`를
   하네스에서 빠뜨려 나온 값이고, **실제는 처음부터 382**였다.
   더 나쁜 것은 **플랜 56이 그 382를 이미 적어 뒀다**는 점이다 — 이 회차의 출발점 문서를
   내가 뒤집어 적었다. 파생값(「빈 여백 190px」)도 함께 틀렸다(실제 124px).
   **교훈: 하네스로 재려면 전역 규칙까지 가져와야 한다.** 안 그러면 실측이 아니라 다른 세계를 잰다.
2. **🔴 행에만 상한을 걸어 «두 번 꺾이는 오른쪽 모서리»를 만들었다.**
   경고·안내·버튼은 454로 남아 947 → 875 → 947이 됐다 — 36회차가 「모서리가 어긋난다」를
   결함이라 부르고 고친 바로 그것을, 이번엔 폼 블록↔액션 행 사이에 새로 만든 셈이다.
   → **모달 자체를 448로 좁히면 계단이 0**이고 컨트롤은 같은 310이다.
   ⚠️ 「520 정렬을 깬다」는 반론은 성립하지 않는다 — **그 명분은 36회차 검수가 스스로 폐기했다**
   (`.end-card`는 `max-width`라 실측 476.5 · 「렌더 기준으로 거짓」). 원칙의 실제 뜻은
   「내용이 정하는 폭으로 보인다」이므로 산문 카드(520)와 폼(448)이 다른 것이 원칙 그대로다.
3. **🟠 서체 배수 1.212가 «도달 불가능한 서체»에서 나왔다.** 스택 마지막이 `sans-serif`라
   `serif`·`AppleGothic`에는 닿지 않는다. 도달 가능한 최악은 NanumGothic **227px**(필요 폭 270) —
   폐기했던 초안 300도 사실은 안전했다. 마진은 무해하나 **근거가 성립하지 않아** 문서를 고쳤다.
4. **🟠 「빈 여백 190 → 52」는 사용자가 보는 상태가 아니다.** 기본 선택은 **접미 없는** 옵션이라
   평상시 필요 폭은 **135px**다. 실제로 줄인 것은 247 → 175px.
5. **🟠 §6.1 문서가 코드와 갈라져 있었다** — 「내 패 옵션 접미 = `— 내 패`」인데 코드는
   `— 내 패 (정답 아님)`다. **이 문자열이 폭 예산의 유일한 입력**이라 §6에 그 사실을 못 박았다.
6. **🟠 §1.5.1 행이 「310px 고정」이라 적었는데 CSS 어디에도 310이 없다** — 1차 상수는 448이고
   310은 파생값이다. 라벨 폭 64를 바꾸면 예산이 조용히 깨진다. 그 관계를 표에 적었다.
   폰 값(320에서 잘린다)도 함께 적었다 — 절 머리말이 「별도 표기 없으면 폰 기준」이기 때문이다.
