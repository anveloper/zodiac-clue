# plan: 접힌 AI 패널의 «빈 상자»를 없앤다 — 예약된 높이를 머리글이 통째로 쓰게

status: done(2026-08-28) · created: 2026-08-28 · src: 개선 루프 22회차 (플랜 41 큐 7번)

## goal
데스크톱 우측 컬럼 맨 위 `#aiPanel`(🤖 AI 대사)이 **머리글 + 빈 크림색 상자**로 보였다.
캡처를 눈으로 보면 **컬럼에서 가장 «미완성»으로 읽히는 요소**다.

## 진단 — «빈 상자»가 아니라 **예약된 높이 + 잘못된 구분선**이었다
17회차는 이 항목을 «패널을 감출까 / 그냥 둘까»의 이진 선택으로 보고 폐기했다(감추면 첫
계측 도착 시 리플로우). **그 프레임이 원인을 안 봤다.**

`.rp-ai`의 `min-height`는 「칩(`✨LLM n · ♻캐시 n · ⚙폴백 n`)이 260px 컬럼에서 **두 줄로
내려가므로**」 예약된 값이다. 그런데 **첫 계측 전에는 `#aiChip`이 비어** summary가 한 줄이다.

실측(1440×900 · 실제 스타일시트 + 실제 칩 마크업을 그대로 옮긴 프로브):

| 상태 | panel | summary | 빈 공간 |
|---|---|---|---|
| 접힘 · 칩 없음 | 65 | **36** | **27px** |
| 접힘 · 칩 있음(두 줄) | **66** | 64 | 0 |

즉 화면이 말하는 것은 «본문이 있는데 비었다»인데 **본문 자체가 없다.**
그리고 예약값 `65`는 칩 두 줄의 실제 높이 **66**보다 1px 모자라 **자기 목적도 못 지켰다.**

## 처방
```css
.rp-fold > details:not([open]) > summary { border-bottom: none; flex: 1; }
.rp-ai { min-height: 66px; }
```
① **구분선을 지운다** — 아래에 본문이 없는데 선이 있으면 «본문이 비었다»로 읽힌다.
② summary에 `flex: 1` — **예약된 높이를 머리글이 통째로 쓴다.**
   `.rp-fold summary`에 이미 `align-items: center`가 있어 글자는 저절로 중앙에 온다.
③ `min-height`를 **66**으로 — 칩 두 줄의 실측 높이. 첫 계측 리플로우가 **0**이 된다.

## 🔴 검수가 뒤집은 것 ① — `justify-content: center`는 **클릭 타깃을 깎았다**
1차 구현이 그것이었다. **글자만 가운데로 옮기고 summary 상자는 36px에 머문다** —
65px 패널에서 «눌러서 펼치는» 영역이 36px로 **줄고 자리까지 옮겨진다.**
실측: 패널 위·아래 히트 테스트가 **둘 다 `DETAILS`**(= summary가 아니다).
게다가 남는 27의 절반이라 제목이 **22.5px 반픽셀**에 얹혔다.
`flex: 1`이면 summary가 **64px**이 되어 타깃이 패널 전체가 되고 배치도 **정수(23.0)**다.

| | 칩 전 panel/summary | 칩 후 | 첫 계측 리플로우 | 패널 히트 | 제목 top |
|---|---|---|---|---|---|
| 패치 전 | 65 / 36 | 66 / 64 | 1px | DETAILS | 22.5 |
| 1차(center) | 65 / 36 | 66 / 64 | 1px | **DETAILS** | **22.5** |
| **채택(flex:1 + 66)** | **66 / 64** | 66 / 64 | **0** | **SUMMARY** | **23.0** |
| 예약 없앰 | 38 / 36 | 66 / 64 | **28px** | SUMMARY | 9 |

## 🔴 검수가 뒤집은 것 ② — 내가 적은 수치가 전부 틀렸다
「summary ~33px · 빈 공간 ~32px · 예약 없애면 32px 리플로우」로 적었다.
실측은 **36 / 27 / 28**이다. `~33`은 `.rp-fold summary`의 padding 8+8 + line-box + border를
빼먹은 값이다. **틀린 수치가 확정 문서 두 곳(`ui-copy` `.md`/`.html`)에 들어갈 뻔했다** —
직접 프로브로 재서 전부 고쳤다.

## 🔴 검수가 뒤집은 것 ③ — `min-height`의 근거는 이미 만료돼 있었다
주석은 그 값을 「`:has()` 미지원 브라우저용 바닥」이라 적어 뒀다. `:has()`는 대상 브라우저가
전부 지원하므로 **죽은 폴백**이었고, 실제로 상시 27px의 빈 자리를 부담시키고 있었다.
지금 66이 서 있는 이유는 **«리플로우 0» 하나**다 — 주석을 그렇게 고쳤다.

## 🔴 검수가 찾은 것 ④ — §4.4가 같은 «칩»을 두 표면에 다르게 적용하고 있었다
§4.4는 「칩은 첫 계측 전 표시하지 않는다 · **문안 없음이 확정본**」 한 줄이었는데,
**폰 HUD 칩 `#aiHudChip`은 정적 마크업으로 `—`를 달고 있고** `main.ts`가 그것을 §4.4의
「계측 전이면 `—`」로 정당화한다. **코드가 옳고 문서가 반쪽이었다** —
§4.4를 표면별 표로 갈랐다(패널 칩 = 표시 안 함 / HUD 칩 = `—`, 이유는 상세 행 유무).

## 안 고른 안 — 패널 칩에 «계측 전» 자리표시
`✨— · ♻— · ⚙—`로 예약 공간을 채우는 안. **필요가 없어졌다** — `flex: 1`이 그 자리를
머리글로 채우므로 채울 빈 공간 자체가 없다.
(초안은 「§4.4가 금지한다」를 근거로 적었는데 **그 근거는 반만 맞다** — 위 ④ 참조.)
