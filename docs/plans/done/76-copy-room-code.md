# plan: 방 코드를 «누를 수 있게» — 코드만 복사 · 키보드 도달

status: done(2026-09-01) · created: 2026-09-01 · src: 개선 루프 56회차 (플랜 73 큐 2번 · 플랜 75 큐 1번)

## goal
53회차가 방 코드를 대기실 1층으로 올렸고 54회차가 그것을 **부를 수 있는 값**으로 만들었다.
그런데 그 코드로 할 수 있는 일이 **읽기뿐**이다:
- `#roomCode`는 `<strong>`이라 **키보드로 도달할 수 없다**(Tab이 지나친다).
- `#copyBtn`은 **링크**를 복사한다. **코드만** 보낼 방법이 화면에 없다.
플랜 73이 「버튼을 하나 더 놓으면 «무엇을 복사하는가»가 다시 흐려진다」며 미뤘고, 그 걱정은 옳다.

## 설계 — **버튼을 늘리지 않고, 코드 자신을 누를 수 있게 한다**
| 대상 | 하는 일 | 왜 안 헷갈리나 |
|---|---|---|
| 방 코드(그 자체) | **코드**를 복사 | 누르는 것이 곧 복사되는 것이다 |
| `[링크 복사]` | **링크**를 복사 | 라벨이 무엇인지 말한다 |

- `<strong>` → `<button>`. 키보드 도달·스크린리더 역할이 **공짜로** 따라온다.
- 생김새는 **그대로 둔다** — 코드는 이미 이 카드의 1층이고, 버튼처럼 칠하면 위계가 무너진다.
  누를 수 있다는 신호는 **hover·focus**에서만 낸다(S9·S13·S14가 그 상태를 잰다).
- ⚠️ **포인터 하한**: 버튼이 되는 순간 S3가 잰다(손가락 44 · 마우스 24).
  코드 줄은 지금 24px(짧은 화면 19.2px)이라 **손가락에서 미달**이다.
  → coarse에서만 키우고, **카드가 자라지 않게** 이웃 여백에서 되받는다(53회차 교훈).

## 🔴 검수가 뒤집은 판단
검수가 실브라우저에서 진짜 마우스·터치·키보드를 쓰고 CDP로 CSSOM·AX 트리까지 읽었다.

1. **🔴🔴 `<strong>`이 `<button>`이 되자 «버튼용 규칙»이 전부 달라붙었다.**
   데스크톱 tier의 `.card button:not(.char)`(0,2,1)가 `.inv-code-v`(0,1,0)를 이겨
   코드를 **20px → 15px로 깎았다**(실측 `119.2×24` → `89.4×24`). 아래 초대 링크와 같은
   무게가 돼 53·54회차가 세운 위계가 데스크톱에서만 무너졌다.
   **그 파일이 `.char`에 대해 똑같은 함정을 바로 위 줄에 적어 뒀는데 반복했다.**
   게이트는 원리적으로 못 잡는다 — S5(글자 크기)는 coarse에서만 돌고 데스크톱은 fine이다.
2. **🔴 내가 근거로 쓴 실측 `89.4×18`이 «수리 전»이 아니었다.** 그것은 1번이 만든 15px 상태의
   값이다. 데스크톱은 원래 24px로 하한을 채우고 있었고, 진짜 미달은 짧은 화면 `95.3×19.2` 하나다.
   **내 변경이 만든 상태를 «원래 그랬다»의 증거로 적었다.**
3. **🔴 `@media (pointer: coarse) { .inv-code-v { min-height: 44px } }`는 죽은 규칙이었다.**
   같은 조건의 `.card button`(0,1,1)이 이미 44를 준다. 「coarse에서만 키운다」는 서사가
   **아무 일도 안 하는 규칙**을 설명하고 있었다.
4. **🔴 자라는 조건과 되받는 조건이 달랐다.** 자라는 것은 `pointer: coarse`, 되받는 것은
   `max-height: 719px` — **독립 조건**이다. 마우스·짧은 화면 8개는 4.8px만 자랐는데
   **25~28px을 깎였고**(5배 과잉), 정작 `phone`은 되받기가 안 걸려 **+8px** 자라
   done-criteria의 「카드 높이 증가 0」이 거짓이었다. → 조건을 결합해 좁혔다.
5. **🔴 터치에서 이 기능은 발견 불가능했다.** 신호를 hover·focus에만 뒀는데 **터치에 hover가 없다**
   (실측: 탭 전 `text-decoration: none`, `(hover: none)` = true). 방을 공유하는 주된 맥락이
   폰인데 그랬다. 게다가 이 파일의 다른 커스텀 버튼이 전부 지우는 `appearance`·
   `-webkit-tap-highlight-color`를 새 버튼만 빠뜨려, **터치에서 유일하게 보이는 피드백이
   UA 기본 회색 상자**였다. → coarse 상시 점선 밑줄 + 두 축 제거.
6. **🔴 «둘 다 3글자라 안 흔들린다»가 공백을 안 셌다.** 실측 `방 코드` 37.33 · `복사됨` 33.75 ·
   `직접 복사` 48.56px → 코드 왼쪽 모서리가 −3.58 ~ +11.23px 움직였다.
   **바로 아래 `#copyBtn`이 같은 결함에 같은 처방(`min-width`)을 이미 갖고 있었다.**
7. **🔴 연타하면 확인이 잘렸다** — 앞 타이머를 안 지워 두 번째 확인이 500ms만 살았다.
8. **🔴 스크린리더가 «무엇을 하는지»를 못 듣는다** — AX 이름이 코드 문자열뿐이었다.
   역할은 `<button>`이 줬지만 **용도는 안 따라온다**(WCAG 2.4.6).
9. **🟠 실패 문안이 이웃과 달랐다**(`직접 복사` vs `직접 복사해 주세요`) → 짧은 쪽으로 통일.
   긴 쪽으로 통일하면 라벨이 59px 밀려 코드가 움직인다.
10. **🟠 죽은 규칙·중복 선언**을 남겼다 → 정리.
