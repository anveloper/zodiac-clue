## 검수가 뒤집은 것 (기록 — 같은 실수를 반복하지 않기 위해)
초안은 **토큰을 안 건드리고 실패한 선택자만 하드코딩**했다. 근거는 「`.sg-n`이 어두운 배경(#1f2b3a)
위라 토큰을 내리면 거기가 나빠진다」였다. **이 근거는 거짓이었다.**

- `#1f2b3a`는 저장소 어디에도 없다. `scripts/gate.config.mjs`의 **낡은 실측 주석**(다른 색·다른 크기
  시절)을 검증 없이 옮겨 적은 것이다.
- `.sg-n`의 실제 배경은 `.sg-row`의 `--wds-tint-primary`(#F3E1D6) — **밝은 표면**이고,
  거기서 #7A6752는 **4.26:1로 `.gi-sub`보다 더 나쁜 기존 AA 미달**이었다.
- 토큰 사용처 32곳을 전수 확인: **어두운 표면은 하나도 없다**(`.hud`·`.rp-panel`도
  `rgba(255,248,239,0.9)`). 토큰을 내리면 나빠지는 곳이 **없다**.
- 초안의 「`.game-item` 배경 #F1E4D0」도 틀렸다 — `.game-item`은 `--wds-bg-normal`,
  #F1E4D0은 `.game-item.selected`다. 랜딩 마크업이 항상 `selected`라 결과만 우연히 맞았다.

**교훈**: 게이트·문서의 실측 주석은 **작성 시점의 코드**를 말한다. 인용 전에 현재 코드로 재확인한다.
(저장소가 이미 아는 규칙이다 — `mafia-content-design.md` §10.6 「`파일:줄` 인용은 커밋 해시와 함께 읽어라」)
