## docs

### 제출물 ③ 분량 재배분 — 60초 요약을 실제 61초로 (`a029005`)
```
                 총 분량      정독    60초 요약 실소요
직전            6,320자    12.6분        95초
1차 축약안      3,671자     7.3분        96초   ← 요약만 안 줄었다
이번            4,376자     8.8분        61초
```
문제는 「길다」가 아니라 **자를 자리가 어긋났다**는 것이었다. 심사자가 확실히 읽는 블록이 유일하게
안 줄고, 심사 축(AI 판정·표현 경계)이 담긴 섹션이 가장 많이 잘려 있었다. 요약을 9행 → 5행으로
줄이고 AI 섹션을 3 → 4항목으로 되살렸다.

### 🔴 닫힌 `<details>`는 인쇄에서 통째로 빠진다
수치의 출처 표를 접어 두자는 설계였는데, 이 문서의 PDF는 `.html`을 인쇄해 만든다. 실측:
```
873.8 kB · 4쪽   접힘 + @media print 강제 펼침  ← 채택
873.8 kB · 4쪽   대조군 details open            ← 동일
766.7 kB · 4쪽   인쇄 규칙 없음                 ← 107.2 kB 증발
```
규칙이 없으면 「스킴하는 독자에게 0자」가 아니라 **PDF 독자에게 영구히 0자**가 된다.
