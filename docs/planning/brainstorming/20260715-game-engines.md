# 무료 게임엔진 조사 — 웹보드/퍼즐 + 웹 배포 + AI 연동

> 작성: 2026-07-15 · 요청: 2jonghun
> 우리 제약: **무료 · 웹(브라우저) 즉시 플레이 · GitHub Pages/Vercel 배포 · AI(Gemini) 연동 · 보드/퍼즐 장르**

---

## 0. 선정 기준
1. **비용**: 완전 무료 or 우리 규모에서 무료(라이선스/로열티 없음)
2. **웹 배포**: HTML5 export → GitHub Pages(정적)로 링크 즉시 플레이
3. **빌드 크기/로딩**: 심사자가 링크 눌러 바로 플레이 → 가벼울수록 유리
4. **AI 연동 용이성**: 서버리스(fetch)로 Gemini 호출이 쉬운가 (JS 계열이 유리)
5. **장르 적합성**: 보드/카드/퍼즐(2D, 턴제) 만들기 좋은가

---

## 1. 추천 Top 3 (우리 용례 기준)

### ⭐ Phaser — 웹+AI 연동 최적 (JS/TS, MIT, 무료)
- **JS/TS 네이티브 2D 프레임워크.** export 단계 없이 곧 웹앱 → GitHub Pages 정적 배포 딱.
- 코어 ~500KB, 커뮤니티 최대(보드/카드/퍼즐 예제 풍부).
- **AI 연동 최강**: 게임이 브라우저 JS라 `fetch`로 서버리스(Edge) → Gemini 호출이 자연스러움.
- 보드/카드/퍼즐/캐주얼에 특히 강함. → **팀이 웹/JS에 익숙하면 1순위.**

### ⭐ Defold — 가장 가볍고 빠름 (Lua, 무료, 로열티 없음)
- King(캔디크러시 제작사)이 만든 엔진 → **퍼즐/캐주얼 DNA.**
- Wasm 웹 빌드 **~1.14MB로 최소·최속 로딩.** 웹+모바일(APK) 동시 export 쉬움.
- Defold License(소스 공개형) — 무료, 로열티/매출 임계 없음.
- 언어가 **Lua**라 러닝커브 약간 + AI fetch는 HTTP 모듈로 가능(Phaser보단 한 단계 번거로움).

### ⭐ Godot — 무료 올라운더 (GDScript, MIT, 로열티 0)
- 완전 오픈소스·로열티 없음. 2D 매우 강함, 보드/퍼즐 적합.
- HTML5 export(~9MB, gzip시↓) + 모바일 export. 에디터 완성도 높음.
- GDScript 학습 필요. 웹 빌드가 Phaser/Defold보단 무거움.

## 3. 결론 / 추천

- **팀이 웹/JS 친숙 → Phaser** (또는 단순 보드/퍼즐이면 **순수 HTML5+TS**도 강력). AI 연동이 제일 매끄럽고 정적 배포 즉시.
- **최소 용량·모바일 동시 + 퍼즐 특화 원하면 → Defold.**
- **에디터 기반으로 편하게, 올라운드 → Godot.**
- **비추/주의**: Construct 3(무료 제한 큼), Unity(웹 빌드 8MB+로 심사자 로딩 부담·오버스펙).

> 핵심: 우리는 "**링크 즉시 플레이 + AI(fetch) 연동 + 무료**"가 핵심이라, **JS 계열(Phaser/순수 웹)** 이 AI 디렉팅 데모에 가장 유리. 무거운 WebGL(Unity)은 피하는 게 안전.
