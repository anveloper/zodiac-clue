# 게임 기획 원페이저 — "방치 홀덤: AI 디렉터" (가칭)

> 작성: 2026-07-16 · 유력안 Ⓕ + AI 자동플레이 디렉터 구체화
> 한 줄: **"플레이어가 자연어로 전략을 지시하면, AI가 그 전략대로 포커/보드를 방치 자동 플레이해 게임머니를 벌고, 그 돈으로 방치 인프라를 키우는 게임."**

---

## 1. 콘셉트 (Ⓕ×Ⓔ×AI 디렉터의 결합)
- NHN 본업(포커/웹보드) × 매출 상단 메타(방치형) × **AI 자동플레이 디렉터**(load-bearing).
- 플레이어는 '치는 사람'이 아니라 **'AI를 지휘하는 디렉터'** = NHN 철학("AI의 다음 단계를 설계") 그대로.

## 2. 코어 루프
1. **지시(Direct)**: 플레이어가 자연어로 전략 입력 — 예: *"타이트하게, 프리미엄 핸드만. 상대가 3벳하면 폴드. 숏스택엔 공격적으로."*
2. **변환**: AI가 지시를 **구조화된 정책(policy JSON)** 으로 변환.
3. **방치 자동플레이(Idle)**: 로컬 규칙엔진이 그 정책으로 핸드를 자동 진행 → 게임머니 획득. (대부분 AI 호출 없이 로컬 실행)
4. **성장(Invest)**: 번 돈으로 **방치 인프라**(채굴기/부스터/새 테이블·상대) 매입 → 수급률·기대값↑.
5. **코칭(Report)**: 세션 종료 시 AI가 **리포트 + 전략 개선 제안**을 자연어로 제시 → 플레이어가 지시 수정 → 1로 순환.
6. **확장**: 상대 난이도↑, AI가 생성하는 새 이벤트/룰 변형으로 리플레이.

## 3. AI 역할 = load-bearing (없으면 게임 성립 X)
- ① **NL 전략 해석** → 정책 JSON 생성 (임의의 자유형 전략을 수용)
- ② **애매한 상황 판단** — 정책으로 안 잡히는 엣지 케이스만 AI에 위임
- ③ **세션 코칭 리포트** — 결과 분석 + 개선안 생성
- ④ (선택) **상대 NPC 성격/블러핑** 생성 ("눈치보는 포커" 결)
- → "자유형 전략을 임의 상황에 적용/코칭"은 규칙 하드코딩 불가 → **LLM만 가능.**

## 4. 무료티어 안정성 설계 (핵심 차별점)
- **AI는 '정책 생성·리포트'에만, 실행은 로컬 규칙엔진.** → 방치 중 **프레임 호출 0.**
  - 전략 해석: 지시 변경 시에만 1콜(드묾) → 정책 캐시
  - 방치 실행: 캐시 정책을 로컬에서 실행(0콜), '어려운 결정'만 가끔 배치 위임
  - 리포트: 세션 종료 시 1콜
- **429/한도 시 fallback**: 캐시된 정책으로 방치 계속 → 데모 절대 안 끊김.
- Gemini Flash + Vercel Edge(키 숨김)로 콜드스타트도 최소.

## 5. 화면 (MVP)
- **메인**: 테이블(방치 진행 시각화) + 게임머니/시간당 수급률
- **디렉팅 패널**: 자연어 전략 입력 + 현재 정책 요약(사람이 읽는 형태)
- **인프라 상점**: 채굴기/부스터/테이블 업그레이드 트리
- **리포트 모달**: AI 세션 요약 + 개선 제안(원클릭 반영)

## 6. 기술 스택
- 클라: **Phaser** 또는 **순수 HTML5 + TS**(2D, 정적) — 링크 즉시 플레이
- AI: **Gemini Flash** via **Vercel Edge Function**(키 env, 클라 노출 X) — 정책 생성·리포트만
- 실행: **로컬 정책 엔진**(정책 JSON 해석→핸드 시뮬)
- 배포: **public repo** → 웹빌드(GitHub Pages 또는 Vercel Hobby)

## 7. MVP 범위 (~08-10)
- [ ] 간소화 게임 1종(심플 포커 or 보드) + 방치 루프
- [ ] NL 전략 → 정책 JSON 파이프라인 1회전
- [ ] 방치 수급 + 인프라 1~2종
- [ ] 세션 리포트 1종 + 지시 수정 반영
- [ ] 데모 안정화(fallback·캐시) + public 배포 + 플레이영상

## 8. 제출물 ④ AI 기술문서 연결
- **정책 스키마(JSON)** + **프롬프트 설계** + **환각 검증**(정책 유효성 체크·판정 로깅) 을 그대로 서술.
- → NHN CTO가 강조한 '안전한 데이터 연결 + 환각 검증' & "AI 디렉팅" 철학과 직결 = 문서가 강해짐.

## 9. 왜 통과각인가 (심사 4박자)
1. **매출 트렌드** — 방치형(매출 상단 메타) 정합
2. **본업 정합** — 포커/웹보드 = NHN 캐시카우
3. **load-bearing AI** — AI 빼면 게임 자체가 성립 안 함
4. **"AI 디렉팅" 철학** — 플레이어=AI 디렉터, 본행사 산출물(에이전트 설계·디렉팅)과 결이 같음

## 10. 리스크 & 완화
- 방치+포커 **밸런싱 난이도** → MVP는 단순 규칙 게임으로 축소, 수치는 후반 튜닝
- 정책 실행 **일관성** → 정책 JSON 스키마 고정 + 유효성 검증 + 실행 로깅
- **사행성 규제** → 게임머니 = **가상재화(현금 환전·현금 구매 없음)** 명시, '채굴기/비트코인'은 테마 명칭
- **범위 초과** → 코어(지시→방치→리포트) 1루프를 먼저 완성, 인프라/이벤트는 확장
