> 작성 2026-07-27 · 사람용 `.html` 동봉 · 대상: NHN NAN 2026 사전과제 제출물 ②
> 목표 길이 **55초**(요건 30~60초) · 구성 **실플레이 클립 6개의 컷 편집** · 원테이크 아님

## 0. 요건 해석과 촬영 보조의 경계 — 이 절이 성실성 증거다

조항: **"실제 플레이 화면만 · AI합성/타인영상 금지"**

| | 허용 | 근거 |
|---|---|---|
| 컷 편집 | ✅ 클립 이어붙이기, 하드컷 | 금지 대상은 합성·타인 영상. 편집 자체는 금지어에 없다 |
| 자막 | ✅ 후처리 텍스트 오버레이 | 화면 픽셀을 대체하지 않음. **③ 문서와 영상 설명란에 "자막은 후처리"를 1줄 명시** |
| 크롭·확대 | ✅ 실제 녹화 픽셀 범위 내 | 없던 화면을 만들지 않음 |
| 표시 계층 조작 | ✅ 우측 컬럼 폭 드래그, 증거노트 높이 드래그, 뷰 드롭다운, 턴 순서 원형 열기, 브라우저 확대 | **전부 게임에 실제로 존재하는 사용자 조작** |
| 반복 촬영 | ✅ [다시 하기]로 여러 판 녹화 후 좋은 테이크 선택 | 각 테이크가 실제 플레이 |
| BGM·나레이션 | ⚠️ **넣지 않는다** | 무음 + 자막으로 확정. 판단 여지를 남기지 않음 |
| **주사위·정답·NPC 판정 개입** | ❌ **절대 금지** | 손대는 순간 "실제 플레이 화면"이 아니다 |
| DevTools 상태 주입 | ❌ | 위와 동일 |
| 가짜 HUD·목업 합성 | ❌ | 조항 정면 위반 |

> **판별 규칙 한 줄**: *"녹화를 멈추고 다시 켜도 같은 일이 일어나는가?"* — 예=허용(표시 계층), 아니오=금지(진실값 개입).
> **자막 정직성 규칙**: 화면에 실제로 찍힌 것만 주장한다. **LLM 배지가 안 찍혔으면 자막에 "LLM"을 쓰지 않는다**(→ 2.C 대체 자막).

## 2. 본 테이크 컷 시트 (선행 개선 완료 후 · 총 55초)

| # | 구간 | 길이 | 한 줄 |
|---|---|---|---|
| A | 0:00–0:10 | 10s | 링크 → 원클릭 솔로 진입 → 주사위 → 방 진입 |
| B | 0:10–0:20 | 10s | [제안] → 용의자·장물 소환 → 반증 |
| C | 0:20–0:29 | 9s | NPC 대사 2연 + AI 카운터 칩 |
| D | 0:29–0:37 | 8s | [계략] → 귓속말 → 증거노트 자동 제외 |
| E | 0:37–0:46 | 9s | 뷰1→2→3→4 연속 전환 |
| F | 0:46–0:55 | 9s | 고발 성공 → 결과 오버레이 |

### 클립 A — 진입 (10초)
- **화면**: 랜딩 카드 → **[혼자 바로 시작]** → `#diceOverlay` 주사위 2개 6프레임 굴림 → `이동 N칸` → 방향키 이동 → 🚪 입구로 방 진입 → 상단 `🎲 내 턴 · 남은 이동 N칸 · 방에서 [제안]`.
- **촬영 조건**: 🔶 선행 = 원클릭 솔로 진입(로드맵 §1.6). 미구현이면 3.A' 사용. 시작 위치 중앙 잔치상 → 최근접 방은 **대청마루(문 11,5)** 또는 **행랑채(문 11,18)**, 이동 2~4칸이면 도달. 주사위 오버레이는 확정 후 1.9초에 사라지므로 **굴림~방 진입을 끊지 말고 한 번에** 녹화.
- **자막**: `설치·로그인 없이 링크 한 번` → `빈 자리는 AI NPC 5명이 채웁니다`
- **대체 컷**: 주사위 눈이 낮아 방까지 못 가면 리매치로 재시작. 그래도 안 되면 [턴 종료] 후 다음 턴 주사위부터 — **주사위를 다시 굴리는 것은 게임 규칙 안의 행위**라 허용.

### 클립 B — 제안과 반증 (10초)
- **화면**: `[제안]` → 모달(용의자 / 훔친 것 / **장소: 대청마루 고정**) → 확인 → 용의자·장물 토큰이 소환 앵커로 **워프** → 로그에 파란 `🔍 [제안]` → 보라 `🛡 … 반증했습니다` + 원 제안 줄에 `반증됨` 배지.
- **촬영 조건**: 방 안이어야 버튼 활성. **반증이 뜨는 조합**을 고를 것(자기 손패에 없는 카드). 미반증(`❗ 정답 후보!`)이 뜨면 그 테이크는 **클립 F 소재로 따로 보관**하고 B는 재촬영. 🔶 선행 = 장소 고정행 + 소환 FX(§2.2).
- **자막**: `방에 들어가 제안하면` → `지목한 용의자와 장물이 그 방으로 소환됩니다` → `반증은 시계방향 첫 사람만`
- **대체 컷**: 소환 FX 미구현이면 **로그 패널 클로즈업**으로 전환(크롭만 사용).

### 클립 C — NPC 대사와 AI 계층 (9초)
- **화면**: 봇 턴 2연속, 말투가 다른 두 캐릭터(예 🐯 `어험— …감히 누구 앞이라고!` / 🐑 `저, 저기… …아니면 말고요.`)의 말풍선이 55ms 타자기로 찍힘 + AI 카운터 칩 `✨LLM 2 · ⚙폴백 0` 증가.
- **촬영 조건**: 🔴 **필수 선행 = `GEMINI_API_KEY` 실제 동작**(§7.1 — 라이브 5/5 폴백 상태). **폴백 상태로 찍고 자막에 LLM이라 쓰면 허위 주장**이다. 🔶 AI 칩 기본 노출(§7.7). 말투 대비가 큰 2인이 연속 턴이 되도록 시작 전 턴 스트립 순서 확인. 봇 대사는 놓치면 다음 턴까지 대기 — 녹화는 계속 돌리고 편집에서 자른다.
- **자막**: `판정은 결정론적 규칙엔진` → `대사만 LLM이 생성합니다` → `✨ = LLM 응답, ⚙ = 규칙 폴백`
- **대체 자막(LLM 미동작 시)**: `NPC 12명 각자의 말투로 말합니다` — LLM 주장 제거.

### 클립 D — 계략 (8초)
- **화면**: 고정 NPC 인접 → `[계략]` → 귓속말 말풍선 + 로그 `🃏 … 계략(엿보기 2·이동 +5)` / `🃏 엿본 카드: 술동이 · 서재 (정답 아님·나만 봄)` → 증거 노트 칩 2개가 **취소선+흐림**으로 자동 전환.
- **촬영 조건**: **모서리 헬퍼 = 2장**이라 증거노트 변화가 크다. 인접은 체비셰프 ≤1(대각 포함). 중앙에서 모서리까지 거리가 있으므로 **주사위 눈이 큰 턴**을 고른다. 엿본 카드가 아직 체크 안 된 **판 초반**에 촬영.
- **자막**: `[계략] — 다른 손님의 패를 몰래 엿봅니다` → `엿본 단서는 증거 노트에서 자동으로 지워집니다`
- **대체 컷**: 노트 변화가 안 잡히면 로그 `(정답 아님·나만 봄)` 클로즈업.

### 클립 E — 뷰 진화 4연속 (9초)
- **화면**: 좌하단 `뷰1 · 2D ▲` → 드롭다운 → 뷰1→2→3→4를 2초 간격. **말들의 위치는 그대로**인 채 표현만 바뀐다.
- **촬영 조건**: 🔶 **유일한 필수 선행 = PLACEHOLDER 배지 제거**(§2.4). 안 하면 뷰3 전환이 "도장 찍히는" 역효과로 찍힌다. 보드에 말이 흩어진 **판 중반(3~4라운드)** 이후. 뷰4는 첫 진입에 한 프레임 지연이 있으니 **리허설로 한 번 켜둔 뒤** 본 녹화. **내 턴 중**(카메라 고정)에 전환.
- **자막**: `개발 진화 4단계를 게임 기능으로` → `2D → 2.5D → 에셋 → 절차적 도트`
- **대체 컷**: 카메라 팬이 겹치면 뷰1→뷰4 **2단계만**(6초로 축소, 남는 3초는 F로).

### 클립 F — 고발 성공 (9초)
- **화면**: `[고발]` → 모달(장소도 선택) → 확인 → 초록 로그 `🎉 사건 해결! 정답: …` → `#endOverlay` `🎉 승리!` + [다시 하기]/[메인으로].
- **촬영 조건**: ⚠️ **가장 확률이 낮은 클립**(개선 후에도 평균 7라운드째). **반드시 마지막에 몰아서** 촬영하고 [다시 하기]로 반복. 정답 확정 경로: 공통 단서 2장 + 계략 엿보기 2장 + 미반증 제안. 🔶 선행 = 제안 턴 고발 가능(§7.5.1). 없으면 두 조각(제안 미반증 / 다음 턴 고발)으로 찍어 컷으로 붙인다.
- **자막**: `누가 · 무엇을 · 어디서 — 셋 다 맞아야 승리` → `정답 고발 성공`
- **대체 컷(우선순위)**: ① **봇의 정답 고발** 종료 화면 + 자막 `NPC도 같은 규칙으로 추리해 사건을 해결합니다` ② **오답 고발 → 탈락** 관전바 + 자막 `틀리면 즉시 탈락, 관전으로` ③ 미반증 제안 로그 클로즈업으로 여운 종료.

## 3. 안전 테이크 컷 시트 (선행 개선 0건 · 현재 코드 그대로 · 총 52초)

> 목적: **08-01까지 요건 ②를 먼저 충족**해 심사 제외 리스크를 0으로. 이후 본 테이크로 교체 업로드.
> 원칙: 지금 확실히 찍히는 것만 담고, **미구현 기능을 자막으로 암시하지 않는다.**

| # | 구간 | 길이 | 내용 | 가능한 이유 |
|---|---|---|---|---|
| A' | 0:00–0:12 | 12s | 랜딩 → [방 만들기] → 🏮 대기실 → 캐릭터 12종을 훑으며 **직업 풀이 패널** 변화 → [잔치 시작] | 전부 구현됨. 4단계 진입을 **캐릭터 도감 쇼케이스**로 전환해 약점을 콘텐츠로 사용 |
| B' | 0:12–0:22 | 10s | 주사위 → 이동 → 방 진입 → [제안] → 로그 2줄 | 구현됨. **보드가 아니라 로그 패널 중심** |
| C' | 0:22–0:31 | 9s | 봇 대사 2연(말투 대비) | 로컬에서 키가 살아있을 때만 LLM 자막 사용 |
| D' | 0:31–0:40 | 9s | [계략] → 엿보기 로그 → 증거 노트 자동 취소선 | 구현됨 |
| E' | 0:40–0:52 | 12s | 뷰1→2→3→4 + 턴 배너 클릭 → **턴 순서 원형 오버레이** | 전부 구현됨. E'를 길게 잡아 F 부재를 메움 |

**안전 테이크 회피 목록**(표시 계층 선택만 사용)
- 소환 로그 `호랑이 대감가 대청마루(으)로` → B'에서 프레임에 오면 재촬영. **또는 조사 헬퍼(30분, §7.14)를 먼저 넣는 편이 훨씬 싸다 — 안전 테이크 전 유일하게 권장하는 선행 작업.**
- 뷰3 PLACEHOLDER 배지 → E'에서 뷰3 체류 1초 이하. (10분 제거 작업 권장)
- 승리 컷 → **처음부터 넣지 않는다.** 턴 순서 원형 오버레이로 마무리.
- 자막 총 6장. 미구현 기능(원클릭 진입·AI 칩·소환 FX)은 **한 글자도 언급하지 않는다.**

## 4. 촬영 순서 체크리스트

> 순서대로 따라 하면 소재가 전부 모인다. 세션 1회 ≈ 90분(안전) / 150분(본, F 반복 포함).

**S0. 준비(10분)**
- [ ] 창 1600×900, 확대 100%, 알림·확장 배너 끄기
- [ ] `pnpm dev` 기동 후 **터미널을 화면 밖으로**
- [ ] 리허설 1판으로 뷰4(`pixel`) 씬 예열
- [ ] 우측 컬럼 320px, 증거노트 300px로 드래그
- [ ] 60fps 확인, 테스트 5초 녹화 후 재생 확인

**S1. 진입(A/A')** — [ ] 페이지 로드 상태부터 녹화 시작 · [ ] 랜딩 1.5초 정지 · [ ] (안전) 캐릭터 4~5개 훑어 직업 풀이 변화 · [ ] 시작~주사위~방 진입 **끊지 않고**

**S2. 제안·반증(B/B')** — [ ] S1에 이어 같은 녹화로 [제안] → 로그 2줄까지 유지 · [ ] 미반증이면 파일을 `zc-*-Fcand-*.mov`로 보관 후 재시도

**S3. NPC 대사(C/C')** — [ ] 녹화 켠 채 [턴 종료] 반복으로 봇 턴 3~4회 · [ ] 말투 대비 큰 2인 연속 구간 타임코드 메모 · [ ] **AI 칩이 없으면 LLM 자막 금지**

**S4. 계략(D/D')** — [ ] 주사위 8 이상인 턴에 모서리 NPC로 이동 · [ ] 인접 후 [계략] · [ ] 말풍선·로그·증거노트가 한 프레임에 · [ ] 변화 후 2초 더 녹화

**S5. 뷰 전환(E/E')** — [ ] **내 턴에** 드롭다운 열고 2초 간격 전환 · [ ] (안전) 턴 배너 클릭 → 원형 3초 유지

**S6. 결말(F, 본 테이크 전용)** — [ ] 녹화 켠 채 끝까지 진행, 종료 시 즉시 [다시 하기] · [ ] **최대 20판 / 90분** 반복 · [ ] 안 나오면 2.F 대체 컷 1순위로 확정

## 6. 편집 · 업로드

- **자막**: 하단 중앙, 흰 글자 + 반투명 검정 띠, 1줄 20자 이내·최대 2줄, 클립당 1~3장, 노출 2초 이상.
- **컷 전환**: **하드컷만**(디졸브·와이프 금지 — "편집으로 꾸몄다"는 인상 최소화).
- **길이**: 최종 55초 ±3초. 60초 초과 시 E를 6초로 축소.
- **YouTube 메타**
  - 제목 `호랑이 생신 잔치 (zodiac-clue) — 실제 플레이 55초`
  - 공개 범위 **공개**(미등록은 심사자 접근 사고 위험)
  - 설명란 필수 3줄: ① 플레이 링크 ② 소스 링크 ③ **"실제 플레이 화면을 컷 편집한 영상입니다. 자막은 후처리 텍스트이며, 게임 화면·판정은 어떤 방식으로도 조작하지 않았습니다."**
