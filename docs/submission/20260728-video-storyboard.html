3. 안전 테이크 vs 본 테이크 — 이 문서의 핵심 설계

🛟 안전 테이크 (52초)

언제 08-01까지 · 선행 개선 미완
목적 요건 ②를 먼저 충족해 심사 제외 리스크 0
선행 작업 0건 (권장 40분: 조사 헬퍼 + PLACEHOLDER 제거)
세션 ≈ 90분
  • 지금 확실히 찍히는 것만 담는다
  • 미구현 기능을 자막으로 암시하지 않는다 (원클릭 진입·AI 칩·소환 FX는 한 글자도)
  • 4단계 진입 약점을 캐릭터 도감 쇼케이스로 전환
  • 보드가 아니라 로그 패널 중심
  • 승리 컷은 처음부터 넣지 않는다 → 턴 순서 원형으로 마무리
  • 자막 총 6장

🎯 본 테이크 (55초)

언제 선행 개선 완료 후 · 교체 업로드
목적 게임의 강점(소환 FX·LLM·승리)까지 담기
선행 작업 🔶 5건 · 🔴 1건 (아래 클립 카드 참조)
세션 ≈ 150분 (F 반복 포함)
  • 클립 A~F 전부. F(승리)가 가장 확률이 낮다 — 마지막에 몰아서
  • LLM 자막은 ✨ 칩이 실제로 올라갈 때만
  • 안전 테이크를 버리지 않는다 — 교체 실패 시 그대로 유지

두 버전이 있다는 것 자체가 설계다. 안전 테이크를 먼저 올려두고 본 테이크로 갈아끼운다.

안전 테이크 회피 목록 (표시 계층 선택만 사용) — ① 소환 로그 호랑이 대감가 대청마루(으)로가 B′ 프레임에 오면 재촬영 (또는 조사 헬퍼 30분 선작업이 훨씬 싸다 — 안전 테이크 전 유일하게 권장) · ② 뷰3 PLACEHOLDER 배지 → E′에서 뷰3 체류 1초 이하 (10분 제거 작업 권장) · ③ 승리 컷 미포함.
