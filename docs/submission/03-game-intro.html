zodiac-clue — 호랑이 생신 잔치

십이지 손님 중 잔치 음식·선물을 훔친 도둑을 추리하는 웹 멀티플레이 추리 게임. 빈자리는 AI NPC가 채워 함께 플레이.

제출물 ③ 게임 소개 NHN NAN 2026 사전과제

심사자 60초 요약

한 판 하려면zodiac-clue.site → [방 만들기] → 캐릭터 클릭 → [잔치 시작] (3클릭, 계정·설치 없음) · 더 빠르게는 ?solo=1
혼자 되나된다. 6인 미만이면 AI NPC가 좌석을 자동 충원 — 1인 접속으로도 정식 규칙 판이 성립.
AI 경계정답·반증·승패 판정 = 결정론 규칙엔진 / LLM(Gemini) = NPC 대사(표현)만. 정답 봉투는 어떤 경로로도 LLM에 넘기지 않는다.
AI가 돌았다는 증거화면 우측 AI 칩(✨LLM · ♻캐시 · ⚙폴백) + 대사 줄마다 경로·지연 배지(✨ 0.9s) + GET /health. 실측 1판 = LLM 19 · 폴백 4 · 캐시 0.
게임이 성립하나사람 승률 2.3% → 21.6%(6인 공정 몫 16.7%) · 봇도 7.0%의 판에서 오답 고발로 탈락한다.

AI를 어떻게 썼는가 — 그리고 그 증거

  • 경계가 먼저다. 정답 봉투·반증·승패·주사위는 결정론 규칙엔진만 만든다. LLM은 대사 한 줄만 쓴다. 검증기가 NarrationInput을 정적 파싱해 정답·손패 필드가 존재하지 않음을 매 실행 증명한다.
  • 페르소나가 대사에만 있지 않다. 봇 고발 판단에 성격에서 유도한 12값이 들어가 p = nerve × (1/조합수)로 지른다. 호랑이는 성급히, 양 목동은 신중 — 최상/최하 14배 차이가 실측된다. 임의 마법상수 0개, Math.random()은 판 시드 1회뿐이라 결정론이다.
  • 계측을 붙였다. narrate()가 경로·지연·모델·폴백사유(6종)를 돌려준다. 전부 폴백이어도 숨기지 않고 사유와 함께 표시한다 — 값을 감추는 칩은 계측이 없는 것과 같다.
  • 그 계측이 우리 주장을 반증했다. "LLM 왕복 ~1.2초"는 실측 평균 926ms, "캐시가 완충한다"던 논리는 히트 0/24로 발동 안 함 — 문서를 실측에 맞춰 고쳤다.
  • AI를 '쓴' 게 아니라 '지휘'했다. 이 게임 자체를 팀이 디스코드로 에이전트에 실시간 지시해 만들었다 — 팀원별 전용 브랜치+독립 워크트리로 격리, 브랜치별 프리뷰 URL로 즉시 확인하되 병합·배포 승인은 사람이 쥔다.
  • 못 한 것은 못 했다고 쓴다. 실호출 경로·지연 분포(C7)는 무료 쿼터를 소모하므로 미판정으로 남겼다 — 추정치로 채우지 않았다.

왜 이 게임인가

  • 장르 = 소규모 퍼즐 추리. 규칙이 검증된 보드게임(클루) 위에 올려 D-23 스코프에서 완성 가능.
  • AI가 없으면 규칙이 안 돈다. 심사자는 혼자 링크를 눌러 플레이하는데, 클루는 상대 0명이면 반증이 성립 안 한다 → AI NPC 좌석 충원은 연출이 아니라 게임 성립 조건이다.
  • 주최사 정합. NHN 게임 매출은 웹보드+퍼즐/캐주얼이 합계 약 70%. 보드 규칙 + 짧은 세션 + 리플레이가 그 결이다. 단, 사행성 소재는 배제(정통 룰만).
  • 테마 = 십이지. 12명을 별도 설명 없이 즉시 식별, 슬롯(플레이어 6 + 고정 NPC 6)과 정확히 맞는다. 카드 ID는 로마자, 화면 라벨만 한글 — 주제 교체 가능한 엔진.

목표 · 조작

목표 — 봉인된 정답(누가·무엇을·어디서)을 추리해 가장 먼저 정확히 고발하면 승리. 예: "게코 도령이 사랑방에서 잡채를 훔쳤다."

  • 이동: 방향키(WASD), 턴마다 주사위 2d6만큼 복도 이동. 방은 입구(🚪)로만 출입, 들어간 턴엔 못 나감.
  • 추리/고발: 방에서 [추리하기] → 지목 → 시계방향 반증. 제안한 턴에 바로 고발(30초 창). 같은 방 연속 제안 불가.
  • 줌 휠 · 화면이동 우클릭 드래그/Space · 시점 좌하단 드롭다운(뷰1 2D ~ 뷰4 도트).
  • 안내: 비활성 버튼은 왜 못 누르는지 툴팁으로 알려줌. 대기실에서 캐릭터에 올리면 직업 뜻·성격 표시.

주요 특징

  • AI NPC 자동 충원 — 봇 = 규칙기반 추리 + LLM 대사, 성격에 따라 도박 고발로 탈락하기도.
  • 비밀 통로 대각 방 3쌍(주사위 없이 순간이동) · 고정 NPC(계략) 다가가면 이동 보너스 + 귓속말 단서(당사자에게만 전문).
  • 증거 노트 · 제안 기록표 개인 메모(내 패·엿본 카드 자동 제외) + 흩어진 제안·반증을 한 행으로 모음.
  • 혼자 두어도 판이 안 멈춘다 — 이탈 좌석은 봇이 인계, 재접속 시 손패·기록 복구. 리매치 즉시.
  • 접근성 — ?cvd=1 색각 대체 표기(색 단독 식별 금지), 포커스 링, 모바일 대응(우측 컬럼 접기).

종료 조건

  • 정답 고발 성공 → 승리(종료). 오답 고발 → 탈락(관전·반증만), 최후 1인 생존 시 승리.
  • 어떤 경로로 끝나든 정답 봉투를 공개 — 답을 모른 채 끝나는 판은 없다.

실행 방법

  • 웹 즉시 플레이: zodiac-clue.site (설치 불필요·무료). 초기 로드 42.38 kB(gzip 17.93 kB).
  • 방 만들기 → 초대 링크 공유. 6인 미만이면 NPC 자동 충원(1인도 시작). ?solo=1 원클릭 솔로.
  • 로컬: pnpm install && pnpm dev → localhost:5173
