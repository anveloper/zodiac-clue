# zodiac-clue

웹 기반 멀티플레이 **클루(Cluedo)형 추리 게임**.
테마: **호랑이 생신 잔치** — 십이지 손님 중 잔치 선물을 훔친 자를 추리한다. NPC 대사는 LLM으로 표현한다.

- 🎮 **라이브(플레이)**: https://zodiac-clue.site  ·  별칭 https://zodiac-clue.vercel.app
- 📚 **문서 대시보드**: https://zodiac-clue.site/docs/ — 설계·플랜·개발일지
- 🖥 **API 서버**: `wss://api.zodiac-clue.site` (OCI, Colyseus)

> 2026-07~08 NHN NAN 2026 사전과제로 시작해 프로토타입을 완성했다. **2026-08-25부터는 과제 산출물이 아니라
> 1년 목표의 실제 게임 개발**로 방향을 바꿨다. 과제 시기 문서는 `docs/archive/`에 동결돼 있다 —
> 현재 상태의 출처가 아니다. 방향과 우선순위는 [1년 로드맵](docs/design/20260825-roadmap-1y.md).

## 구조 (pnpm 모노레포)

```
zodiac-clue/
├── apps/
│   ├── server/     # Colyseus (Node/TS) — 방·상태동기화·클루 룰·NPC 결정(권위 서버)
│   └── client/     # Phaser 3 + Vite (TS) — 보드 렌더·카메라·입력·네트워크
└── packages/
    └── shared/     # 공용 타입·카드/방/성격 데이터(용의자=십이지12·장물6·장소9)
```

## 기술 스택

- **서버**: [Colyseus](https://colyseus.io) 0.15 — 방/로비/상태동기화. 비밀정보(손패·정답 봉투)는 동기화하지 않고 개별 private 전송.
- **클라**: [Phaser 3](https://phaser.io) + [Vite](https://vitejs.dev) + `colyseus.js` — 2D 탑뷰 추적 카메라·줌·트윈 이동·플로팅 HUD.
  **렌더러는 하나다.** 과제 시기의 Three.js 2.5D·픽셀 뷰(뷰2·3·4)는 2026-08-25에 제거했다 → [결정 근거](docs/plans/active/20-phaser-only-pivot.md)
- **AI(NPC 대사)**: Google **Gemini**(`gemini-flash-lite-latest`). 원칙 — **결정·진실값은 규칙엔진, 표현(대사)만 LLM**. 실패 시 규칙 폴백. → [AI 기술문서](docs/design/20260720-ai-tech-doc.html)
- **배포**: 서버 GitHub Actions(SSH→OCI), 클라 Vercel(Git 연동). main push 자동배포. → [배포 세팅](docs/design/20260720-deploy-setup.html)

## 개발

```sh
pnpm install
cp apps/server/.env.example apps/server/.env    # GEMINI_API_KEY 채우기(없으면 규칙 폴백 대사)
cp apps/client/.env.example apps/client/.env

pnpm dev          # 서버(:2567) + 클라(:5173) 동시 실행
pnpm dev:server   # / pnpm dev:client
pnpm -r typecheck # 타입체크
pnpm verify       # 게이트 일괄(번들·시뮬·GPU·문서정합·스크린)
```

브라우저 http://localhost:5173 → 방 만들기/초대(`/room/<코드>`)로 멀티 접속. 6인 미만이면 NPC 자동 충원.

## 앞으로 (1년)

프로토타입과 «실제 게임»의 차이는 기능 개수가 아니라 **혼자 들어와도 판이 서는가 · 다시 들어올 이유가 있는가**다.
분기 목표와 근거는 [1년 로드맵](docs/design/20260825-roadmap-1y.md)에 있다. 요약:

| 분기 | 주제 | 핵심 질문 |
|---|---|---|
| Q1 (~2026-11) | **기반 정리** | 렌더러 단일화·엔진/콘텐츠 분리·계정과 저장이 없는 채로 어디까지 가나 |
| Q2 (~2027-02) | **혼자서도 성립** | 매칭·NPC 난이도·튜토리얼 — 접속자 1명일 때 게임이 되는가 |
| Q3 (~2027-05) | **다시 올 이유** | 진행 저장·전적·시즌 콘텐츠·계략 다양화 |
| Q4 (~2027-08) | **주제 교체 가능성** | 엔진 위에 두 번째 콘텐츠(마피아 등)를 올려 «엔진»임을 증명 |
